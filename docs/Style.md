# 界面风格

颜色、圆角、字体从主题与 `AppUiTokens` 读取，不在业务调用处写死。换外观设置后全局控件一起变。

## 当前主题

配色对齐 NativeTavern：内置 `ThemePreset`（浅色 / 灰色 / 石板 / Claude / 薄荷 / 紫色 / Hermes / 海洋 / 深色现代 / 石墨 / 深林 / 咖啡 / 午夜 / 暮色 / Cursor 深色），亮色槽与暗色槽**各自记住**一套 `ThemeTokens` + `packId`；自定义色可改当前槽后「保存为主题」或「恢复默认」。内置亮色预设（浅色 / 灰色 / 石板 / Claude Code / 薄荷 / 紫色 / Hermes）共用一套飞书式对比度：主字 `#1F2329`、次要字 `#646A73`、分割 `#DEE0E3`、强调蓝 `#3370FF`、气泡 `#F5F6F7`；各套仅 `editorSurface` / `sidebarSurface` 色调不同（见 `ThemeTokens.lightPreset`）。暗色预设默认主字 `#EBEBEB`、次要字 `#B0B0B0`（配色主题如石墨 / 深林等仍用略暖略冷的提亮主字，见 `ThemeTokens.darkPreset`）。设置 → **外观** 可改：

| 项 | 选项 | 落点 |
| --- | --- | --- |
| 主题模式 | 列表行点开抽屉选：跟随系统 / 浅色 / 深色；行尾显示当前 | `AppearanceSettings.mode` → `MaterialApp.themeMode`；`showAppSheet` |
| 主题颜色 | 浮层抽屉（`AppSheetSize.half`）选 NT 内置 + 用户包；亮/暗分槽；行尾显示当前包名 | `showAppSheet`；`lightTokens`/`darkTokens` + `lightPackId`/`darkPackId`/`customPacks` |
| 自定义颜色 | 浮层抽屉（`half`）；逐项 token | `showAppSheet`；`ThemeTokens`；`AppColorPicker`；行尾 `AppForwardIcon` |
| 字体 | 浮层抽屉（`half`）；系统默认 / 本机 / 导入 | `AppearanceSettings.fontFamily` + `fontPath`；`AppFontPickerRow` + `showAppSheet` |
| 字体大小 | 滑块 **12–20 px**，步长 **0.5 px**（默认 15） | `AppearanceSettings.fontSize` → body 字号；其它角色按相对 15px 比例缩放 |
| 圆角大小 | 滑块 0–24 px，步长 1（默认 10）；**曲率连续**（超椭圆） | `AppearanceSettings.cornerRadius` → `AppUiTokens.radius` / `AppShapes.continuous`；例外：[`AppSearchField`](../lib/foundation/widgets/app_search_field.dart)、底栏胶囊、[`AppCircleButton`](../lib/foundation/widgets/app_circle_button.dart) 固定几何，不跟此滑块 |

`AppTheme.light|dark` 分别取亮/暗槽 tokens，经 `AppColorTokens` 映射到 Material `ColorScheme`（对齐 NativeTavern）：`accent` → `primary`，`secondaryAccent` → `secondary`，`tertiaryAccent` → `tertiary`；选中底用 accent / 过程钢蓝 / 转折琥珀 / 结束紫），不跟主题包走；内容区按行排布插头，左侧「进入」、右侧每条出线为可点标题按钮（继续 / 岔路 / 添加），与 [`GraphPort`](../lib/foundation/graph/graph_port.dart) 水平对齐；标题最多 15 ### 聊天（对齐 NativeTavern Zephyr）

- 色：`ThemeTokens` 的 `chatBackground` / `characterBubble` / `userBubble` / `chatText` / `dialogueText` → [`AppChatColors`](../lib/foundation/theme/app_chat_colors.dart) ThemeExtension。
- 形：[`AppChatChrome`](../lib/foundation/theme/app_chat_chrome.dart) — 气泡 `ContinuousRectangleBorder`（外侧上角直角、默认圆角 **30**，可调 **0–50**）、composer 近胶囊半径 **50**；用户气泡为 accent 叠 surface，角色气泡用 `characterBubble`。
- 引号对白（`"…"` / `“…”` / `「…」`）用 `dialogueText` + bold。
- 聊天背景：[`AppChatBackground`](../lib/foundation/theme/app_chat_background.dart) + [`AppChatBackgroundLayer`](../lib/foundation/widgets/app_chat_background.dart)（主题 `chatBackground` 为底，可叠纯色 / 内置渐变预设；默认「主题默认」）。
- 游玩聊天壳：[PlayChatView](../lib/play/play_chat_view.dart)（列表顶对齐；底部按 composer 实测高度留白，避免挡气泡/回复选项；新消息自动滚到底；「回复选项」在列表末尾随气泡滚动；浮动 composer；空态大头像 +「开始对话」；助手生成中显示 typing 气泡）。Composer 左侧对齐 NT：`选择模型`（`smart_toy_outlined` → [`pickAndApplyTextModel`](../lib/settings/ai_model_picker.dart)，半屏两步：模型 → 思考程度）与 `聊天设置`（进 [`ChatSettingsPage`](../lib/play/chat_settings_page.dart)，非全局设置）；无「重新开始」。[`AppChatComposer`](../lib/foundation/widgets/app_chat_composer.dart) 底行只有字段与发送键（左侧 `leading` 槽留给聊天页的模型 / 设置胶囊）；创作助手不再在输入框旁放编辑范围开关。[`ChatUiSettings`](../lib/domain/settings/chat_ui_settings.dart) 控制行距（默认 **1.4**）、段间距（默认 **8**）、气泡圆角、角色/我的头像显隐、头像在气泡上方或并排、是否显示思考过程、聊天背景；正文经 [`AppChatDialogueText`](../lib/foundation/widgets/app_chat_dialogue_text.dart) 按空行分段；思考过程用 [`AppChatReasoning`](../lib/foundation/widgets/app_chat_reasoning.dart) 折叠块。助手回复从接口取 `reasoning_content` / `reasoning` / `thought`，或正文前导 `<think>` 等标签（[`ThinkTagParser`](../lib/foundation/ai/think_tag_parser.dart)），写入存档 `chat[].reasoning`；开关只控制显隐，不重新拉取。顶栏右侧在末条为助手且未生成中时显示 `重新生成回复`（`AppCircleButton` + `refresh_rounded`，对齐 NT AppBar regenerate）。聊天页顶栏标题经 `AppPage.titleWidget` 用 `AppTextRole.subtitle`（`titleMedium` **16**），小于其它页的 `pageTitle`（**24**）；视觉小说游玩不显示标题，`AppPage.showTitle: false`。
- 视觉小说舞台（同页 [`PlaySessionPage`](../lib/play/play_session_page.dart)）：没有软件标题栏，整屏是舞台。背景由 [`AppPage.background`](../lib/foundation/widgets/app_page.dart) 铺满整页——桌面窗口标题栏、手机状态栏后面也是同一张舞台图（无图时用 `colorScheme.surface` 底色），控件位置不变；**当前说话人立绘**叠在背景上、贴底（优先 `Appearance.spriteAssetId`，否则 `CastMember.avatarAssetId`；旁白/无说话人不显示）；站位优先 `Appearance.slot`，否则按 `CastMember.facing` 对侧（面向右→左、面向左→右），左右约半幅宽、居中略宽。对白用 [`AppDialoguePanel`](../lib/foundation/widgets/app_dialogue_panel.dart) 贴底（左右/底边 `pagePadding`，再加安全区底 inset）：**高度只由行数与字号决定**（[`AppDialogueChrome.panelHeight`](../lib/foundation/theme/app_dialogue_chrome.dart) = 首行 + 行数×字号×1.5 + 内边距），不随文字长短跳动；`ClipRRect` 主题圆角 + `BackdropFilter` 高斯模糊（`blurSigma` 14）+ 半透明底色（跟随主题或 `VnUiSettings.backgroundHex`，alpha 取不透明度）；首行是固定高度的角色名槽（旁白也保留空槽），右侧可放「1/2」页码；正文 `AppDialogueChrome.bodyStyle`（`FontStyle.italic` 用于旁白，`color` 取 `VnUiSettings.textHex`，空则用主题正文色；角色名同色、空则用主题强调色），行数上限用 [`paginateText`](../lib/foundation/text/text_paginator.dart) 按 `TextPainter` 实测切页。无选项时不画中央按钮，点舞台先翻当前句的下一页、翻完才推进；选项 [`AppButton`](../lib/foundation/widgets/app_button.dart) 垂直居中叠在对白上方（最大宽 420）。对白下方为控制栏：返回（`arrow_back`）/ 后退 / 前进 / 快进 / 重新生成 / 游玩设置（`settings_outlined`）六枚 [`AppIconButton`](../lib/foundation/widgets/app_icon_button.dart) 用 `Wrap` 居中排布（`spaceXs` 间距，窄窗自动换行，不溢出）；前进还可「接续推进」且先翻页，快进只在有已看内容时可点，其余不可用走 `onPressed: null` 的禁用色；生成中「重新生成」位置换成 [`AppBusyIndicator`](../lib/foundation/widgets/app_busy_indicator.dart)（18px 主题色环）。状态提示（错误 / 已读进度）放在面板上方的 `caption` 行，不占面板固定高度；对白框内不出现「正在写这一段」类状态行。游玩设置见 [`VnSettingsPage`](../lib/play/vn_settings_page.dart)：行数 / 字号 / 不透明度，以及「颜色」分区的背景颜色与文字颜色（各自可跟随主题），存 [`VnUiSettings`](../lib/domain/settings/vn_ui_settings.dart)。
- 回复选项芯片：[`AppChatChrome.tappableMenuChip`](../lib/foundation/theme/app_chat_chrome.dart)（主题圆角 + 浅底描边，对齐 NT Zephyr menuChip）。

`AppDockedPanel`（同款表面/圆角/限宽），经 `AppNavShell.bottomPanel` 叠在胶囊之上的空隙里；开关为约 180ms 自底部滑入/滑出（`Curves.easeOut`，无过弹），程序关闭走 `AppDockedPanelState.dismiss`；有面板时 `AppNavShell` 铺透明遮罩挡住 body `Expanded` 列表外，滚动时保持可见。带说明的分区头用 `AppSectionHeader(subtitle: …)`：标题与副标题间距 `spaceXs`，整块下边距见上。禁止业务侧直接 `showModalBottomSheet`。可折叠行尾用上下箭头（`AppDisclosureIcon`）；打开抽屉的行尾可用右箭头（`AppForwardIcon`），不用「展开/收起」文案。列表行 / 滑块 / 字体行带 leading `icon`。`AppListTile` 尾标按内容宽度占位，标题/副标题吃满中间剩余宽度，副标题最多两行，写不下才省略。[`AppSettingsNestedColumn`](../lib/foundation/widgets/app_nested_settings_group.dart) 默认无额外空隙（行自带发丝线）。二级行 / 滑块设 `nested: true` 仅多一段左侧缩进；说明性 [`AppSurface`](../lib/foundation/widgets/app_surface.dart)(`nested: true`) 仍可用浅底 + `outline` 描边。`AppSegmented` 选项可带 `icon`（在文字左侧），行高与纯文字时一致；页内分页用 [`AppUnderlineTabs`](../lib/foundation/widgets/app_underline_tabs.dart)：仅文字，选中项用 `primary` 颜色 + 文字下方 **2px** 短横线（未选中为透明，线宽随文字），整条下方一条 `AppTheme.listHairline` 通栏发丝线；首项文字左缘与正文 gutter（16）对齐，轻于 `AppSegmented` 的填充胶囊，放在标题正下方；宽度不够时整条**横向滚动**（标签保持自然宽度，不挤压、不溢出）。销毁确认用 [`showAppConfirmSheet`](../lib/foundation/widgets/app_confirm_sheet.dart)（标题 + 一句说明 + 取消/确认，危险操作用 `danger`）。

## 布局与窗口

- 桌面最小客户区见 `AppTheme.windowMinSize`（覆盖顶栏与窗口按钮）。
- 页面壳在更小约束下收缩或隐藏标题/操作，禁止黄黑溢出条。
- 桌面窗口位置与大小由基础设施记忆（`WindowGeometryStore`），关闭后再开恢复；最大化状态一并保存。

## 响应式导航（双布局）

断点与壳层在 `lib/foundation/layout/app_layout.dart`、`AppNavShell`、`AppPage`（参考 NativeTavern）。**同宽度 ⇒ 同壳层**（桌面竖屏 / 窄窗与手机一致）；导航按宽度切换，不按 `TargetPlatform`。桌面自定义标题栏只铺背景；软件标题栏在其下（见「沉浸式标题栏」）。

首页、设置与情节图复用 `AppNavShell`：

| 页面 | 条件 | 导航 / 标题 |
| --- | --- | --- |
| 首页 | 宽度 `< 600` | **主胶囊**会话 / 故事 / 玩法 / 我；**无**软件标题栏（搜索/工具在正文顶） |
| 首页 | 宽度 `≥ 600` | **左侧导航栏**；同样无软件标题栏 |
| 设置 | 宽度 `< 600` | **悬浮胶囊底栏**；chrome 下有软件标题栏（返回+「设置」） |
| 设置 | 宽度 `≥ 600` | **左侧导航栏**；同样 chrome 下软件标题栏 |
| 情节走向 | 任意宽度（`forceCompact: true`） | **主胶囊**画布 / 卡片 + **右侧独立胶囊**全图（`AppBottomNavExtraCapsule`，仅画布可用） |

子父页切换统一走 [`AppSlidePageRoute`](../lib/foundation/widgets/app_page_route.dart) / [`pushAppSlide`](../lib/foundation/widgets/app_page_route.dart)（约 280ms 自右滑入，底层略左移；故事流用 [`AppStorySlidePageRoute`](../lib/foundation/widgets/app_page_route.dart)）；**底栏四分区仍用 `IndexedStack`，无页间滑动**。故事库进入/退出文件夹时，**仅文件与文件夹列表**左右整页滑动（约 280ms；进入：当前页左移出、子页自右滑入；返回相反；搜索与面包屑不动；先取数再同帧换路径；进/出方向按当前 path key 区分，因 `AnimatedSwitcher` 出页只 reverse controller、不包 `ReverseAnimation`）。首页四分区不画 `AppPage` 标题；会话/故事为「搜索 → 工具行 → 列表」，工具行与搜索同用 `pagePadding`；「我」为右上齿轮 + [`MeUserHeader`](../lib/home/me_user_header.dart)（与设置 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart) 同行高：[`AppPersonAvatar`](../lib/foundation/widgets/app_person_avatar.dart) **40** + 名字/简介 + `AppForwardIcon`）。故事库四种布局（详细列表 / 简洁列表 / 网格 / 紧凑网格）与列表头像形状（圆 / 方 / 竖矩）见 [`LibraryDisplayController`](../lib/home/library_display_prefs.dart)；网格卡用 [`AppCoverTile`](../lib/foundation/widgets/app_cover_tile.dart)，头像用 [`AppShapedAvatar`](../lib/foundation/widgets/app_shaped_avatar.dart)；本地图片（文件或字节）统一走 [`AppImage`](../lib/foundation/widgets/app_image.dart)（按布局宽度限制解码、失败回退占位）。有 `assets/cover.*` 的故事在列表用 `AppShapedAvatar.background` 铺封面、网格把封面图作为 `AppCoverTile.cover`，无封面仍用首字占位。故事列表末尾加号控件与故事同形（网格为无底栏封面卡，列表为同形头像钮，皆无文案）；带 `AppPressScale` 与 Ink hover/按下反馈；点开菜单项统一 `AppListTile`。

窄屏底栏尺寸见 `AppLayout.bottomNavHeight` / `bottomNavHorizontalInset` / `bottomNavBottomInset` / `bottomNavBlurSigma`；胶囊圆角固定为高度一半，不跟控件圆角滑块走。胶囊以 `Stack` 叠在内容之上，四周留白透明；本体为半透明表面 + `BackdropFilter` 毛玻璃模糊（对齐新版 iOS 胶囊质感）。底栏项与侧栏项按下用统一 [`AppPressScale`](../lib/foundation/widgets/app_press_scale.dart)（缩至 `AppTheme.pressScale` **0.92**，`pressScaleDuration` **120ms**，`easeOutCubic`）。图标胶囊置 `busy` 时把图标换成 [`AppBusyIndicator`](../lib/foundation/widgets/app_busy_indicator.dart) 的旋转进度环（字号同档、不溢出胶囊），点击仍有效；进度环是常驻动画，测试里别对它 `pumpAndSettle`。`AppPage` 不预扣底边，`AppPageBody` 与情节图画布读 `MediaQuery.padding.bottom`（壳层会加上胶囊高度）以免内容被挡。以通栏列表为主的页面用 [`AppPageBody.list`](../lib/foundation/widgets/app_page.dart)（仅上下 `pagePadding`）；**行数可能很多**的通栏列表（剧情元素库、分类子页等）改用 [`AppPageLazyList`](../lib/foundation/widgets/app_page.dart)（同 padding，`SliverList` 按需构建，页签/说明等少量固定内容放 `header`），切页签与滚动不因一次性布局全部行而卡顿；多块列表无行间距时用 [`AppListTileStack`](../lib/foundation/widgets/app_list_tile.dart)。

## 沉浸式标题栏

五个平台的内容都进入系统栏区域，不留一条独立的系统标题栏；顶栏填充色与页面背景一致。

- **双层顶栏**（[`AppPage`](../lib/foundation/widgets/app_page.dart)）：
  1. **窗口 / 状态 chrome**：与页面同色背景。桌面为自定义标题栏（高度 `AppTheme.titleBandHeight` **44**，macOS 可抬高对齐红绿灯）；**禁止**在此层放返回、标题、`actions` 或任何业务文字/控件。移动端仅 `statusInset`（`titleBarHeight: 0`）。传 `background` 时这一层改用透明带，让整页背景（视觉小说舞台图 / 底色）一直铺到窗口顶边与手机状态栏后面；带高、正文起点、窗口按钮位置都不变。
  2. **软件标题栏**（`AppTheme.pageTitleBarHeight` **44**）：在 chrome **下方**；非主页放返回（**32**）+ 标题（`AppTextRole.subtitle`）+ `actions`。主页 `showTitle: false` 时不画这一层；视觉小说游玩同样是 `showTitle: false`（全屏舞台，返回 / 重新生成 / 设置在底部控制栏）。
- 桌面窗口能力：macOS 红绿灯区可拖动；Windows / Linux 自绘最小化/最大化/关闭（宽度够时才画）；双击切换最大化。不驱动第二套业务布局。
- 圆形图标按钮：形状**一律正圆**，不读外观圆角滑块。[`AppCircleButton`](../lib/foundation/widgets/app_circle_button.dart) 默认 **40**；[`AppIconButton`](../lib/foundation/widgets/app_icon_button.dart) 为同款 `ghost` 封装（故事工具行 + / 导入 / 更多等）。软件标题栏返回 **32**；`ghost` 未按下无底色，按下/悬停仍有 ink；主色 CTA 用 `filled`（`AppCircleButton.fab` 默认 **54** / 图标 **30**）。画布角上次要圆钮显式 `ghost` FAB。窄屏底栏时 FAB 用 [`AppFabLocation.aboveCompactBottomNav`](../lib/foundation/widgets/app_fab_location.dart) 抬高。
- 故事详情 [`AppDetailSection`](../lib/foundation/widgets/app_detail_section.dart)：扁平分区（无外卡）；标题行 icon+标题+编辑，可选 `subtitle` 一行小字（`caption`，最多两行）排在标题下方，用于条数与估算 token；分区 icon **上下居中在标题 + 副标题整块**上，编辑钮仍贴标题顶对齐；条目上下 `spaceInline`、底用 [`AppListHairline`](../lib/foundation/widgets/app_list_hairline.dart)；条内文案 `compactLabel` / `compactBody`，标签 `compactTag`（主色浅底 chip）。默认每区只建前 `initialVisibleCount`（**8**）行，超出用 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart)「还有 n 条」展开剩余；单条正文 `previewLines`（**3**），折叠时截断测量串。封面 16:9 横向贴边、直角无圆角；右上角圆形钮可更换图片（存 `assets/cover.*`，`ProjectMeta.coverPath`），图片走 [`AppImage`](../lib/foundation/widgets/app_image.dart) 失败时回退首字占位。窄屏底栏胶囊高度/边距见 `AppLayout.bottomNav*`。

通道没有实现时（测试、还没接上的窗口）仍显示页面顶栏，不画窗口按钮。

## 界面文案与多语言

界面字符串一律从 `context.strings` 取，组件里不新增中文字面量；已迁移的页面不再直接写中文。

- 基础 chrome 契约：[`app_localizations.dart`](../lib/foundation/l10n/app_localizations.dart)（`cancel` / `save` / `delete` / `discardEditsTitle` 等通用词 + `AppLocalizationsDelegate` + 回退）。foundation 控件只依赖这一层，不 import 业务文案，目录可直接拷到新项目。
- 产品文案契约：[`app_strings.dart`](../lib/app/l10n/app_strings.dart)（继承基础契约；`AppStringsSetup` 登记所有语言、`supportedLocales` 与 delegates）。中文实现：[`app_strings_zh.dart`](../lib/app/l10n/app_strings_zh.dart)。
- 加语言：新建一个 `AppStrings` 子类实现全部 getter，再加入 `AppStringsSetup.translations`；漏实现任何一条都编译不过，编译器即翻译完整度清单。未注册 delegate 的测试环境（`test/support/test_app.dart` 之外的裸 `pumpWidget`）自动回退中文，不会抛错。
- 带数量的文案用方法（如 `countLabel(n)`、`lastPlayed(kind, relative)`、`worldBookSize(entries, alwaysOn, tokens)`），不要在 widget 里拼句子；语言差异（语序、量词）留在实现文件里。
- 布局枚举的用户可读名（布局模式、头像形状）由 [`library_display_labels.dart`](../lib/home/library_display_labels.dart) 从 `AppStrings` 取，枚举本身只留 `icon` / `next` 等无文案成员。
- 文案风格仍按 `ui-copy`：面向用户、副标题不加句号、无实现腔。

**不迁入文案表的内容**（属于数据或标识，不是界面 chrome）：内置剧情元素与分类种子、AI 提示词模板与工具描述、`AppLog` 日志、主题 token / 内置预设名称、系统字体名。这些若要本地化，另按「数据本地化」处理，不要塞进 `AppStrings`。

**已迁移**：首页会话 / 故事分支、故事详情、创作入口与创作助手、剧情元素库 / 分类 / 包 / 编辑器、游玩模式选择、聊天设置、视觉小说游玩设置、游玩会话页与聊天视图、设置各面板与子页（含诊断日志）、世界书 / 角色编辑器（列表与编辑抽屉展示立绘、可单张重画）、画面页（首行两个一键按钮 + 画风 / 角色立绘 / 场景图条目：左侧 56px 缩略图或图标、右侧标题与两行提示词预览；点条目进全屏抽屉改图与提示词）、情节走向编辑器（画布选中站底部场景预览、站抽屉可重画场景、连线抽屉、全览）、角色卡导入、分阶段创作；枚举显示名（主题 token 与预设、AI 供应商与思考程度、情节站种类、设置分区）改由 `AppStrings` 方法 / 同层 helper 解析，枚举本身只留 id 与 icon。
**待迁移**（仍为字面量）：分阶段创作的预览拼接文本（`_formatWorldBook` / `_formatCast` / `_formatMain`，属写入数据而非界面 chrome）；角色卡解析 / 整理等领域异常文案。

未使用官方 ARB / `flutter gen-l10n`：仓库没有代码生成链路，且 `foundation/l10n` 需要保持可移植（生成类绑在 app 层，会让 foundation 反向依赖业务）。纯 Dart 契约换来编译期完整性检查、无生成步骤、改名可全局重构；接第三方翻译或需要 ICU 复数时再切 ARB，届时只需把 `AppStringsZh` 的文案搬进 `.arb`。
