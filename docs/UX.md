# AnoWorld 用户体验预览

本文描述**用户看见和做什么**，不是实现细节。数据落点对照 [Core.md](./Core.md)、[MainBeat.md](./MainBeat.md)。功能设计变更时同步改本文，避免体验和 schema 各说各话。

界面文案必须面向用户：短、口语、说清能做什么；不出现 Beat、Edge、Transition、schema、token、NativeTavern、LLM、「接入」等内部词或注释口吻。副标题/说明行简明扼要、不说教，末尾不加句号。对用户说：故事、设定、角色、情节、场景、对白、选项。技术设置用通俗标签（服务地址、密钥）。更细约定见 `.cursor/rules/ui-copy.mdc`。

界面文案集中到 [`app_strings_zh.dart`](../lib/app/l10n/app_strings_zh.dart)（契约见 [`app_strings.dart`](../lib/app/l10n/app_strings.dart)），widget 里通过 `context.strings` 读取；加新语言只需再写一个实现并登记。已迁移范围与待迁移清单、为什么不用 ARB，见 [Style.md](./Style.md)「界面文案与多语言」。

## 游玩体验目标（先记住这个）

开玩时二选一（**视觉小说** / **聊天**），进局后不能再改。两种玩法共用设定、角色与（可选）情节素材，但推进方式不同。

- **聊天（对齐酒馆）**：严格「AI 说一段 → 你回一段 → AI 再接着」；底部可点回复选项当作你的发言。情节节点若有，只作提示词里的软约束，不把聊天绑进视觉小说拍子机。
- **视觉小说**：主线站 + 区间 AI；全屏背景、底部对白、点屏推进、选项居中；有出边则收敛，无出边则开放续写（选项里「继续 / 告一段落」）。
- **情节是辅助**：没有脉络也能靠设定与角色开聊或开玩；有脉络时聊天多一层走向提示，VN 多一层站间收敛。

创作入口仍然是「导入 / 贴故事 / 几句提示词」，不是先教用户画节点。对照数据层见 [Core.md](./Core.md)。

## 结论：schema 不该由用户填

一份**能开玩**的故事，系统里至少要有：

| 系统里有什么 | 玩家/作者要不要手填 | 三条路径里谁来补 |
| --- | --- | --- |
| 故事名 | 要，或从导入文件名带出 | 用户确认一下即可 |
| 全局 AI 预设（玩法 → 预设） | 可不碰；内置默认即可 | 想换气质或导入酒馆 preset 时去玩法 |
| 世界观 / 设定 | 角色卡、小说里通常已有 | 路径 1/2 自动填；路径 3 用一句提示词生成 |
| 角色 | 手建或从卡摘取；可勾一名 **主角** | 同上 |
| 主线概括 + 大情节站 + 分支 | 角色卡里往往没有完整剧情树 | AI 从素材或提示词生成**脉络骨架**；用户可微调站名/走向 |
| 站与站之间的对白过程 | 用户不应手写整本 | **游玩时 AI 实时生成**（可预写开场钩子，非必须） |
| 图片 | 没有也能先玩（占位） | 生图或稍后导入，不挡「开始游玩」 |

所以：**对用户并不复杂——入口是导入或提示词，出口是直接玩；情节图用来事后改大走向，不是第一步。** 用户看到的「能玩」，靠的是「设定/角色可用 + 游玩时 AI 能演下去」；情节骨架是加分项，不是硬门槛。

角色卡通常只有人和设定。导入后即可开玩（开放续写）；若再生成脉络，则多一层分支与收敛。

## 共同壳：三条路之后长一样

无论从哪条路进来，用户落在同一个故事上，之后只有三件事：

1. **玩**：点「开始游玩」先选 **视觉小说** 或 **聊天**（[`showPlayModeSheet`](../lib/play/play_mode_sheet.dart)），选定后整场锁定，并**新建一条存档**（同一故事可有多条）。聊天为酒馆式气泡：助手一轮在左、你一轮在右；空输入不发送；点「回复选项」或打字发送都算你的一轮，随后 AI 再生成；可「换一批」选项。输入栏可换模型（先选模型再选思考程度）、进**聊天设置**（[`ChatSettingsPage`](../lib/play/chat_settings_page.dart)：行距、段间距、气泡圆角、思考过程显隐、角色/我的头像与位置、聊天背景含内置渐变/纯色；只影响聊天页）；顶栏右侧可重新生成上一条助手回复。开玩与每轮进度都会**自动写回**该存档（顶栏只显示故事名，无玩法前缀、无手动保存）。首页**会话**点一条即续玩该槽（不经故事详情）；「更多」里仍可打开故事或删这一条。
2. **改**：觉得不对，改设定/角色、改某站目标或分支，或让 AI 重写脉络/重来某一段过程。
3. **补画面**：可先占位；再生图或导入，绑到场景/角色上。

玩和改之间随时切换，不必「写完每一句才允许玩」。

## 首页（底栏：会话 / 故事 / 玩法 / 我）

首页用 `AppNavShell` 四分区（窄屏悬浮胶囊底栏 / 宽屏左侧栏；断点 **600**，与平台无关——桌面竖屏与手机同一套）：**会话** / **故事** / **玩法** / **我**。首页**不显示**软件标题栏（`AppPage.showTitle: false`）；桌面仍留空白自定义标题栏（仅背景，可拖动）。非主页（设置、故事详情、游玩等）在窗口/状态 chrome **下方**有软件标题栏（返回 + 标题 + 操作，高度 **44** / `pageTitleBarHeight`）；桌面自定义标题栏内不放控件与文字。有搜索的分区：搜索在最上，工具按钮在搜索下一行（正常 `pagePadding`）。全局**设置**在「我」页内容区右上齿轮进入，底栏不再有单独设置胶囊。软键盘对齐 NativeTavern：Android `adjustResize`，[`AppPage`](../lib/foundation/widgets/app_page.dart) 默认随键盘收缩；正文与居中对话框上移避让。悬浮底栏与收起态创作助手按 [`keyboardPinOffset`](../lib/foundation/widgets/app_bottom_nav_icon_capsule.dart) 钉在屏幕物理底边（可被键盘盖住，不跟着对话框弹跳）；展开的创作助手面板仍留在可视区内。抽屉按 `viewInsets` 上移；收起只 [`unfocus`](../lib/foundation/focus/app_keyboard.dart)。

- **会话**：已开启的游玩进度（视觉小说与聊天同一列表；按最近存档时间；副标题带玩法）；最上胶囊搜索（[`AppSearchField`](../lib/foundation/widgets/app_search_field.dart)，不跟外观圆角滑块），下一行右侧**多选**；多选时同行换为取消 / 全选 / 删除。切到本页或从故事返回会刷新；点进直接续玩；「更多」半屏菜单与其他列表一致，用带 icon 的 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart)：继续游玩 / 打开故事 / 删除存档（只清进度，`danger`）；空态「去故事」仍可用。
- **创作助手**：[`CreateAssistantOverlayScope`](../lib/home/create_assistant_overlay.dart) 把 [`CreateAssistantHost`](../lib/home/create_assistant_host.dart) 插进根 `Overlay`（磨砂图标与底栏胶囊同款玻璃壳），**不随子页 push 重建**；路由变化后会再置顶，但抽屉 / 对话框等弹层（`PopupRoute`）打开时整体不绘制也不接收点击（`Offstage`，面板状态保留），弹层关闭后恢复，保证「当前故事」选择列表等弹在助手之上。仅在故事分区（非多选）及 [`pushStoryRoute`](../lib/home/story_assistant_navigation.dart) / [`AppStorySlidePageRoute`](../lib/foundation/widgets/app_page_route.dart) 子页显示；切到会话/玩法/我，或盖上不透明非故事页（如游玩）时隐藏。点开时由锚点向左上展开为半屏圆角面板（[`CreateAssistantBloomShell`](../lib/home/create_assistant_bloom_shell.dart)）；面板底与圆形按钮之间留一小段间距，[`CreateAssistantBloomOutline`](../lib/home/create_assistant_bloom_outline.dart) 预置一条整体轮廓（面板 + 细腰 + 圆形锚点）模拟水面张力；**点面板外任意区域**或再点锚点图标收起——收起只是隐藏，面板与进行中的回合都还在（生成完成后直接弹确认抽屉）；回合进行中锚点（含收起后的胶囊）的星形图标换成旋转进度环，收起也看得到还在写（`CreateAssistantController.generating` → [`AppBottomNavIconCapsule`](../lib/foundation/widgets/app_bottom_nav_icon_capsule.dart) `.busy` / [`CreateAssistantBloomShell`](../lib/home/create_assistant_bloom_shell.dart) `.busy`）。每个故事各有一份对话记录，换故事即换记录；记录跟随故事卡存在，删故事卡时一起删掉。当前故事、对话与输入框草稿写入本地（[`CreateAssistantDraftStore`](../lib/home/create_assistant_draft_store.dart)），下次打开恢复。锚点与情节画布「加一站」等高（[`AppBottomChromeMetrics`](../lib/foundation/widgets/app_bottom_nav_icon_capsule.dart)），不改动画布右下角工具位置。故事页（含情节图 / 世界书 / 角色 / 剧情元素选择等子页）打开时，创作助手自动跟着切到该故事——子页盖在父页之上，返回后落回父页的故事——用户仍可在顶部手动改选。选中故事后，在输入框说一句想要的走向，创作助手先按五层目录自行取用该故事的设定、角色与剧情元素，再写情节骨架（`main.replace` → [`CreateAgentLoop`](../lib/domain/ai/create/create_agent_loop.dart)）；结果先弹半屏预览（几站、几处岔路、每站一句话），确认后写入故事（有旧情节时提示会替换），再通知已打开的故事详情 / 情节图 / 世界书 / 角色 / 剧情元素选择页按最新内容重新读取（[`ProjectChangeNotifier`](../lib/app/project_change_notifier.dart) 按故事记版本号，[`ProjectChangeWatcher`](../lib/app/project_change_watcher.dart) 每个页面各自比对，所以一次写入会让所有打开的那几个页面一起刷新）。它也能查剧情元素库并勾选、或新增一条（`plot.list_elements` / `plot.select`）：新条目进全局库并勾给当前故事，同样先逐条确认再写。未选故事或没配写故事服务时直接回一句提示，不发请求。
- **故事**：无分区标题；最上胶囊搜索，下一行左为**面包屑**、右为**更多**。列表/网格**末尾**有故事形加号按钮（无文字、无底栏，整块可点，语义标签「添加」）；点开半屏菜单，选项一律 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart)：新建空白故事 / 粘贴故事 / 分阶段提示词 / 导入角色卡 / 导入故事包 / 新建文件夹 / 试用「雨夜投宿」。**导入故事包**选 `.anoworld` 或 `.zip`（内含 `manifest.json` + `project.json` + `assets/` 全量资源）；导入后进故事详情，可直接开玩。点故事进详情；故事「更多」半屏菜单同样用无区分度 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart)（带 icon）：**开始故事**（先选玩法再开新存档）/ **查看故事**（详情）/ **编辑故事**（创作截面）/ **导出故事包**（打成 `.anoworld`，含设定、角色、情节与全部图片资源；不含游玩存档）/ **删除故事**（`danger` 强调色，创作助手里这个故事的对话一起删）。文件夹「更多」同款列表：**打开** / **重命名** / **解散文件夹** / **删除文件夹**（`danger`）。点文件夹进入下一层；新建/重命名文件夹用屏幕居中对话框（[`showAppPromptDialog`](../lib/foundation/widgets/app_prompt_dialog.dart)）；更多里改显示方式与头像形状、进多选；多选时工具行换为取消 / 全选 / 移到 / 删除，并隐藏该加号按钮。故事有 `assets/cover.*` 时，**列表头像与网格封面显示真实封面图**（无封面仍用首字占位），其余行为不变。
- **玩法**：全局素材库与写作预设入口，无分区标题，直接列条目。**剧情元素**（[`PlotElementsLibraryPage`](../lib/play/plot_elements_library_page.dart)，软件标题为「剧情元素库」）：标题下用下划线页签分 **全部 / 分类 / 包**，页签下方直接接内容（无分区头，无额外间距）。全部按原顺序列出；分类页签列出各分类（名称 + 条数），点进 [`PlotElementCategoryPage`](../lib/play/plot_element_category_page.dart) 子页看该类条目，页内可改名、加一条。包页签列出元素包（名称 + 条数 + 前几个关键词），点进 [`PlotElementPackPage`](../lib/play/plot_element_pack_page.dart) 子页勾选哪些元素进这个包，页内可改名、删除包；删元素时自动从各包里摘掉该 id。出厂分类 **日常 / 情感 / 冲突 / 危机 / 悬疑 / 心理 / 灵异** 可改名。软件标题栏右侧三个圆形按钮依次是 **更多**（全部恢复默认）/ **加一条** / **新建分类**（在包页签下换成 **新建包**）。编辑条目时也能改分类。出厂种子可改可删，单项/全部恢复默认；故事侧只勾选，不在此改库。**预设** 点进 [`AiPresetPage`](../lib/settings/ai_preset_page.dart)（内容即 [`AiPresetPanel`](../lib/settings/ai_preset_panel.dart)）：标题下空一行是一排圆形按钮 **新建预设** / **保存当前设置为预设** / **重命名当前预设** / **删除当前预设** / **导入预设** / **导出预设**；其下第一条即当前预设（行标题就是当前预设名，副标题「控制输出风格和边界」，点开半屏抽屉只列内置 / 我的两组预设，抽屉里没有其它按钮，长按也没有菜单）；再下 **采样**（无副标题）直接列出生成项（单次输出、上下文、温度、Top P、流式）。**单次最长输出** 滑块 256–32768 token（[`AiGenerationSettingsPanel`](../lib/settings/ai_generation_settings_panel.dart)）：思考型模型会先花几千 token 推理，写长 JSON（如 60 站情节图）要调高，否则回复会被截断。**高级采样**点进子页（[`AdvancedSamplingPage`](../lib/settings/advanced_sampling_page.dart)）；最后 **预设提示词**（[`PromptManagerPanel`](../lib/settings/prompt_manager_panel.dart)）段列表全部显示，可拖动手柄改顺序，标题行右侧的 **加一条** 新建自定义段（先填名字，进段后再写文案）、**恢复默认顺序** 只把内置段换回出厂次序、自定义段留在原位置；不可编辑段可点进只读查看，自定义段编辑页标题栏右侧的 **删除** 删掉该段。有自定义段时标题行还多一个 **多选**（长按自定义段同样进入）：行首变成勾选点，点行切换选中，标题换成「已选 N」并给出 **全选 / 删除**，删除前确认；内置段在多选下显示锁定，点它提示不能删。内置预设不能改名或删除（提示先存为自己的）；导出写的是当前实际生效的采样与提示词。套用预设会写入 `AiSettings.generation` 与 `AiPresetCatalog.promptManager`，在面板内改动即为当前生效值。
- **我**：无分区标题；内容区顶部右侧齿轮进设置；其下为当前身份行（[`MeUserHeader`](../lib/home/me_user_header.dart)，行高与设置列表项一致），点开 [`PersonaSettingsPage`](../lib/settings/persona_settings_page.dart) 管理多套身份（选用 / 编辑 / 添加 / 长按或编辑页删除；内置默认身份不可删）。

库内文件夹与故事归属落在 `{library}/folders.json`（[`ProjectFolderRepository`](../lib/domain/repositories/project_folder_repository.dart)），与故事包目录分开。

## 设置（从首页「我」进入）

设置内另有分区导航（窄屏悬浮胶囊底栏 / 宽屏侧栏）：**通用** / **外观** / **AI** / **关于**。

- **外观**：**主题**分组含主题模式（点开抽屉选跟随系统/浅/深，行尾显示当前）、主题颜色 / 自定义颜色；**界面**分组含字体等。列表类抽屉卡片相对屏幕两侧内缩、限宽，默认半屏，**抽屉内列表行贴满卡片左右**；主题颜色行尾显示当前包名；自定义颜色含「保存为主题」「恢复默认」；字体可选系统默认 / 本机 / 导入；字体大小/圆角滑块。各项列表与滑块左侧有图标。改完立即作用到全局封装控件。视觉约定见 [Style.md](./Style.md)。
- **AI**：写故事与生图分开选服务商（半屏浮层抽屉，标题与说明固定不随列表滚）。服务地址、密钥为整行列表项（左标题/说明，右显示当前值；密钥打码），点开抽屉编辑后保存；切换服务商会记住上次内容。能自动查找模型的，填好后会拉出列表；点「模型」选用，也可点「查找模型」。文本通道另有 **思考程度**（自动 / 最低 / 低 / 中 / 高 / 最高）。
- **AI**（[`AiSettingsPanel`](../lib/settings/ai_settings_panel.dart)）：文本/生图 **服务地址、密钥、模型**；文本另有 **思考程度**（[`AiReasoningEffort`](../lib/domain/settings/ai_settings.dart)，请求时 OpenAI 用 `reasoning_effort`、OpenRouter 用 `reasoning.effort`）。**生图质量**：采样步数（默认 **12**，4–40）；立绘/场景宽高可滑块手调（256–2048，步长 64）或选预设（[`ImageGenSizePresets`](../lib/domain/settings/ai_settings.dart)，场景含多档 **16:9**）；默认立绘 768×1152、场景 1216×832；出图后超分默认关。下方 **视觉小说演出**：**每段最少句数**（[`AiSettings.minBridgeLines`](../lib/domain/settings/ai_settings.dart)，默认 **10**，1–10）写少了会自动重试一次；**情节图最少站数**（[`AiSettings.minGraphStations`](../lib/domain/settings/ai_settings.dart)，默认 **20**，4–60）约束助手整图重写与分步创作骨架；**站内选项**（[`InStationChoiceFrequency`](../lib/domain/settings/ai_settings.dart)，关闭 / 很少 / 有时 / 较多）只影响站内续写要不要弹选项，出站分叉始终有。写故事/游玩/分步创建走全局 [`AiPromptContext`](../lib/domain/ai/ai_prompt_context.dart)（预设 + 通用里的 Persona + 故事背景）。
- **预设 · 预设提示词**：与 ST 相同的段类型与 `prompt_order`；左侧拖动手柄可改顺序；可编辑段点进改文案，不可编辑段点进只读查看；标题行右侧 **加一条** 新建自定义段，自定义段编辑页标题栏右侧可删除该段，**多选** 可一次删掉多条自定义段；游玩与创作拼装时用 **世界书**、**角色**当卡字段注入对应段（实现渐进对齐）。发送前如何拼成模型输入见 [PromptPipeline.md](./PromptPipeline.md)。
- **玩家身份**：首页「我」点当前身份进入管理页（可建多套、点选当前、编辑/删除）；名字与简介参与 `{{user}}` 等宏。设置 → **通用**：Debug 构建下可见 **高级** → **诊断日志**（内存环形缓冲、`ListView` 懒加载；控制台与复制文案带 `HH:mm:ss.SSS` 时间戳），正式版不显示。
- **宏 / 变量**：预设与世界书、角色、对白模板里的 `{{…}}` 按酒馆规则展开（含常用宏与变量语法，实现对照 NT）。
- **关于**：应用图标与一句话说明。

## 路径 1：导入酒馆角色卡

**用户想要的感觉**：选一个卡 → 看软件读懂了什么 → 勾选留下 → 写入故事再改。

**当前实现**：故事页末尾「添加」→「导入角色卡」→ [`CharacterCardImportPage`](../lib/create/character_card_import_page.dart)；支持 `.json`（V2/V3/旧平铺）与带 `chara`/`ccv3` 的 `.png`；读入后**自动去掉网页标记**（正文以 Markdown 存）；可再点「清理格式」；确认后「写入故事」进入创作截面（先填素材，不强制立刻开玩 / 生成脉络）。**封面**：PNG 卡直接把卡面图写入故事封面（`assets/cover.png`）；JSON 卡若同目录有同名 `.png`（[`readCardCoverSidecar`](../lib/data/card_import/card_cover_sidecar.dart)）也一并带上；导入页会预览这张封面，没有图则提示可在故事页更换。macOS 沙盒需 `files.user-selected.read-write`（Debug/Release entitlements）才能读所选卡文件。

### 用户做的事

1. 选择角色卡文件（可多张：第一张作主角与故事名，其余当配角）。
2. 看「读到了这些」：角色、世界书条目；用开关划掉不要的（卡内 system 等不写入故事，提示去设置调全局提示词）。
3. 可选「清理格式」：规则去 HTML，保留 Markdown。
4. 点「写入故事」：生成故事并打开创作截面，继续改设定 / 角色 / 情节。
5. （后续）再生成短脉络骨架并开玩——本阶段不挡写入。

### 软件自动做的事

| 卡里常见内容 | 填到 |
| --- | --- |
| PNG 卡面图（或与 JSON 同名的 PNG） | 故事封面（首张带图的卡；导入页可预览） |
| `scenario` | 世界书 · 常驻「情景」 |
| `character_book` 启用条目 | 世界书条目（`constant`→常驻，否则带关键词） |
| `first_mes` | 世界书 · 常驻「开场素材」 |
| `alternate_greetings` | 备选开场（默认不勾选） |
| `name` / `description` / `personality` / `mes_example` | 角色 |
| `system_prompt` / `post_history_instructions` | 不写入故事包；导入后可提示粘贴到设置 → 提示词 |
| 正则、插件 | 不导入 |
| 酒馆 preset 文件 | 玩法 → 预设 导入 |

### 体验要点

- 确认页要短：每块一行标题 + 一两行预览，开关决定去留。
- 读卡失败留在本页，不丢已选文件以外的状态；写入失败同样留在确认页。
- 图可以后补；不强制等生图结束。

## 路径 2：导入小说或一段剧情

**用户想要的感觉**：贴上一段故事 → AI 拆成能玩的故事 → 开玩 → 哪段不对改哪段。

### 用户做的事

1. 新建故事，粘贴正文，或导入文本文件。可写一句补充（例如「只做到雨夜投宿为止」「主角是第一人称」）。
2. 等一页结果：设定摘要、登场角色、情节列表（每场一行标题 + 一句发生了什么）。
3. 可删掉某场、改标题，或点「按原文重写这一场」。
4. 点开始游玩。

### 软件自动做的事

从正文抽出并写入：设定、角色、主线概括、**有序大情节站（含一句话目标）与分支**；原文没有分支时，补少量合理岔路并保留「按原文继续」类走向。对白过程留给游玩时 AI（可选预写第一站钩子）。

长文不要一次吞完。体验上先做**用户划定的这一段**（或自动截成「第一章 / 前若干字」并告诉用户范围）。这一段的骨架能玩后，再提供「根据后文续接下一站」。

### 体验要点

- 结果页先给人读「故事被拆成了哪几站」，不要先丢一张节点图。
- 和原文出入大时，用户能对单站重写目标/重滚，而不是整篇推倒。
- 同样允许无图开玩。

## 路径 3：从空白开始，分阶段写提示词

**入口已接通**（路径 2 仍为占位）：故事页「添加」→「分阶段提示词」→ [`StagedCreatePage`](../lib/create/staged_create_page.dart)。需在设置 → AI 配好写故事服务（[`OpenAiChatClient`](../lib/foundation/ai/openai_chat_client.dart) + [`StagedCreateActions`](../lib/domain/ai/staged_create_actions.dart)）。

**目标体验**：每个阶段只写一两句人话；阶段 3 产出的是**脉络骨架**（概括 + 大站 + 分支），开玩后站间由 AI 实时演。

| 阶段 | 用户写什么 | 生成并填入（目标） | 用户此时能做什么 |
| --- | --- | --- | --- |
| 1 世界 | 「雨夜的边城，人们靠传闻活着」 | 设定 | 改设定；还不能完整游玩 |
| 2 人物 | 「少年想离开，客栈老板知道出路」 | 角色 | 改人设；仍建议先有脉络再玩 |
| 3 走向 | 「今晚必须出城，在客栈做一个选择」 | 主线概括 + **大情节站（含目标）+ 分支/结局出口** | **可以开始游玩**（过程戏现场生成） |
| 4 画面（可后做） | 「城门冷色、客栈暖色」或直接生图/导入 | 场景图、立绘 | 再玩时看到图（本阶段尚未做） |

阶段 3 结束就是「能玩」的分界：骨架合法且文案服务可用即可开玩，**不要求**创作时写满对白。

**当前实现**：路径 3「走向」只生成 `summary` + 大站（含 `synopsis`）+ `default`/`branch` 边（`beats` 可空）；故事页「继续创作」打开创作截面（设定 / 角色 / 情节 / **画面**）；游玩时空拍进 [`BridgeGenerateAction`](../lib/domain/ai/bridge_generate_action.dart)，失败或未配文案服务时用「前往：{下一站}」保底；样例「雨夜投宿」仍带预写对白作静态对照。路径 1/2 导入未做。

**阶段 4 画面（MVP）**：创作枢纽 →「画面」→ 先用文本模型生成可控的立绘/场景提示词（`CastMember.visualTags` / `facing`、`StoryNode.imagePrompt`，可手改朝向）→ 经 ComfyUI（NoobAI）批量出立绘与每站场景图（步数/分辨率/超分读设置）→ 写入 `assets/` 并绑定 `avatarAssetId` / `backgroundAssetId`。立绘提示强制白底+描边+朝向标签，落盘前做边缘 flood-fill 去背成透明 PNG；场景保持完整环境。情节图选中站时底部预览该站场景图，站编辑抽屉可「重新画场景」；角色列表与编辑抽屉显示立绘，可「重新画立绘」（[`VisualImagePipeline.regenerateScene`](../lib/domain/ai/visual/visual_image_pipeline.dart) / `regenerateAvatar`）。VN 舞台铺节点背景图，说话人透明立绘按 `Appearance.slot`（或 `facing` 对侧）左右摆；无图仍可玩。

### 创作助手（通用 Agent，已接通）

在故事分区或故事子页点右下角创作助手：面板顶部是「当前故事」（不再有单独的「创作助手」标题），打开故事页时自动切到该故事，也能手动改选；没有编辑范围开关——一次回合全层可读可写，改哪层由模型按你的说法判断。实现见 [`CreateAssistantPanel`](../lib/home/create_assistant_panel.dart) + [`CreateAgentRunner.runTurn`](../lib/domain/ai/create/create_agent_runner.dart) + [`CreateAgentLoop`](../lib/domain/ai/create/create_agent_loop.dart)。

- **先看后改**：系统提示里只放五层的目录（设定/角色标题、站点与出边数、已选剧情元素），模型觉得不够才调工具去读某一条的正文或某个字段；不需要改动时直接回一句话，不弹确认。
- **情节图**：无图或要整图重写 → `main.replace`（至少约 **20** 站、上不封顶，按丰富度加站；分叉目标要拉开；叶可为终局或开放续写）；有图则 `main.patch` 增量改站/边。
- **世界书 / 角色**：`world.patch` / `cast.patch` 提议改条目或角色字段，确认后写回。读可跨层，写也可以在一轮里连写几层，最后合并成一张确认单。
- 确认：半屏抽屉按层分组列出改动，可**单独勾选**要写回的条目，并显示字段级「原 / 改」差异；只写选中项，多层改动一次保存。整图重写占一行，并明说会换掉现有站（有预写对白则一起清掉）。预览与回放见 [`patch_preview.dart`](../lib/domain/main/patch_preview.dart) / [`patch_review_sheet.dart`](../lib/home/patch_review_sheet.dart)。
- **收起不打断**：点面板外或切走分区只会隐藏面板（[`CreateAssistantPanel`](../lib/home/create_assistant_panel.dart) 始终留在树上，隐藏期间 `Offstage` 不绘制也不收点击），正在跑的回合照常继续；写完直接弹确认抽屉，不需要先重新展开助手。
- 刷新：写入后经 [`ProjectChangeNotifier`](../lib/app/project_change_notifier.dart) 通知详情与情节图重读。
- 未选故事、未配写故事服务、模型不支持工具调用、模型输出不可解析时，只回一句可读提示，不改动故事。

每一阶段：输入框 → 生成 → 就地预览可编辑 → 下一步 / 重写。不要在阶段 1 打开情节画布。未配置文案服务时留在当前阶段提示去设置，不丢已写入内容。

### 体验要点

- 提示词旁边给一句例子；预览讲「有哪几站、怎么分支」，不要堆内部字段名。
- 「重写这一阶段」只动这一阶段产物（改人物不默默拆掉已生成的脉络；冲突时标出来让用户决定——待补）。
- 游玩中过程不对：可「重来这一段」或改站目标后再玩；大走向不对：回情节图或重滚阶段 3。

## 故事详情（点进一个故事）

从故事库点一个故事进入 [`ProjectHubPage`](../lib/project/project_hub_page.dart)：上方**封面**横向贴边、直角（有 `assets/cover.*` 时显示真实封面，否则首字占位；右上角可换本地图片 / 恢复默认）；下方扁平分区 **世界书**、**角色**、**情节走向**、**剧情元素**（无外卡；改 AI 气质去设置）。每区标题下用一行小字给体量与估算 token（世界书「n 条设定，m 条常驻，x token」、角色「n 个角色，x token」、情节走向「n 个节点，x token」、剧情元素「已选 n 项，x token」；空区不显示这行，由下方空态说明）。剧情元素区展示本故事已勾选的关键词与描述；空态「还没选剧情元素」，点编辑进勾选页。每区标题行带编辑；条目以发丝线分隔（标题、标签、正文，世界书条目对齐酒馆式常驻/关键词标签）。每区默认只先显示前 **8** 条，多出来的用「还有 n 条」一次展开；单条正文默认三行预览（折叠时不把超长全文拿去排版），右侧**展开**与**复制**（复制仍是全文）。右上角 **继续创作**；右下角 **开始游玩** 用 [`AppCircleButton.fab`](../lib/foundation/widgets/app_circle_button.dart)（先弹出玩法选择）。

## 创作截面（故事内）

故事详情点「继续创作」，或创作流程中直接进入 [`CreateHubPage`](../lib/create/create_hub_page.dart)：软件标题为「创作·{故事名}」（无正文副标题）；标题栏右侧圆形钮**改故事名**（居中对话框，改完立刻保存并刷新标题）；其下四条 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart) 通栏入口（`AppPageBody.list` + `AppListTileStack`，与设置同款）：世界书 / 角色 / 情节走向 / **剧情元素**（[`PlotElementsPickPage`](../lib/create/plot_elements_pick_page.dart)，只从全局库勾选，不改库；可跳转玩法库管理）；副标题给数量与估算体量：世界书「n 条设定，m 条常驻，x token」、角色「n 个角色，x token」、情节走向「n 个节点，x token」、剧情元素「已选 n 项，x token」，空列表仍用「还没有…」/「还没选」；token 写原数，不缩写 k、不带「约」。`token` 由 [`TokenEstimator`](../lib/foundation/text/token_estimator.dart) 估算（非 ASCII 约 1 字 1 token、ASCII 约 4 字 1 token，向上取整），文本取自实际注入内容（世界书合并文本、角色档案字段、主线摘要/节点/对白/选项/连线、剧情元素提示块），汇总在 [`ProjectTokenEstimate`](../lib/domain/project/project_token_estimate.dart)；同一套文案（`describeWorldBookSize` 等）在故事详情页四个分区头复用。勾选页标题下同样有 **全部 / 分类 / 包** 下划线页签：全部直接开关；分类页签列出各分类，点进子页只做勾选（建分类、改名都在玩法库里）；包页签列出元素包，打开开关（或点条目）一次性把包内元素全部勾上，关掉则把包内元素全部取消，副标题显示「已选 m / n 条」。包之间不互斥，应用与取消只动本包的元素；若与已单独勾过的元素、或另一个已应用的包有重叠，应用前先弹确认，说明哪几条会并入本包（之后取消本包时会一并取消）、哪几条仍由别的包保留。取消包时，别处仍需要的元素不会被取消（同样先告知）。不再有「勾选进本故事」分区头；选中数量以「已选 n」小字显示在软件标题栏右侧（为 0 时不显示）。设定/角色编辑页、导入角色卡勾选列表同样套用该组合。

| 入口 | 用户在改什么 | 编辑页 |
| --- | --- | --- |
| 世界书 | 世界事实条目：常驻或关键词唤起；长按多选批量删；编辑抽屉右上保存 | [`WorldBookEditorPage`](../lib/create/world_book_editor_page.dart) |
| 角色 | 姓名、简介、性格等；**至多勾一名主角** | [`CastEditorPage`](../lib/create/cast_editor_page.dart) |
| 情节走向 | 大站与分支（原节点画布） | [`MainGraphPage`](../lib/create/main_graph/main_graph_page.dart) |

副标题用当前故事摘要（条数/人数/站数/已选剧情元素数 + token），不堆内部字段名。情节图仍只服务大走向，不是创作入口的第一步。

## 微调：三条路共用，而且是可选的

开玩之后，用户只会因为「这里不对」进来，而不是为了填满 schema。

| 用户觉得 | 打开的界面 | 背后改的数据 |
| --- | --- | --- |
| 人设/世界观偏了 | 创作截面 → 世界书 / 角色 | WorldBook / Cast |
| 这一站目标不对 / 分支不对 | 创作截面 → 情节走向 | nodes / edges / synopsis |
| 过程戏这段不对 | 游玩中「重来这一段」或创作里预写钩子 | 区间会话 / 可选预写 Beats |
| 想多一个结局或岔路 | 创作截面 → 情节走向 | nodes / edges |
| 输出不对 | 玩法 → 预设（提示词分段） | 全局 AiPreset |
| 图不好看 | 图片：再生或换自己的 | 资源槽 |

全端同一套节点编辑器；底栏可切「画布 / 卡片」，见下一节。

## 游玩中：选择、分支与续写

**聊天**：进场 AI 先写开场；你说话或点回复选项后，AI 再写一轮；回合清晰，不替你说话。

**上下文怎么进**：两种玩法同一套规则（[`PlayContextSelector`](../lib/domain/ai/play_context_selector.dart)），不是把整本书塞给模型——

- **必进**：常驻设定（`alwaysOn`）、主角字段、主线概括、当前站目标。
- **命中进**：设定条目按 `keys` 命中近几轮正文才注入（没填 `keys` 的条目按标题匹配），上限 6 条；剧情元素按关键词命中，上限 4 项。
- **不进**：其余条目与未命中的剧情元素留在库里，创作助手仍可点名读取。

扫描范围是最近 6 轮对话或最近 2 拍正文（取末尾约 2000 字）。想让某条设定在相关场景一定出现，给它填关键词即可。

**放不下时先丢旧的**：预算 = 设置里 **上下文** 减去 **单次输出**（[`ContextBudget`](../lib/domain/ai/context_budget.dart)）。聊得久了，最早的几轮对话会先被丢掉，正文里留一句「更早的 n 条对话已省略」；VN 的区间摘要只带最新一截。常驻设定与主角字段不参与丢弃。默认预设的窗口很大，不动 **上下文** 滑块就不会发生裁剪。

**视觉小说**（[`PlaySessionPage`](../lib/play/play_session_page.dart) VN 舞台）：

1. **全屏背景**：背景图铺满舞台；暂时没有图时整面留空（不占顶部小卡片）。
2. **底部对白**：当前句在屏幕下方；角色名用主题强调色粗体；旁白不显示「旁白」或角色名，正文斜体。
3. **点击继续**：没有选项时不出现「继续」等按钮，点屏幕任意处推进下一句；生成中不可点。
4. **中央选项**：有选项、保底「前往：某站」、或本段结束「重新开始」时，选项叠在画面中央（在对白框上方），对齐常见 SLG 做法。
5. **回退条**：对白框下方一排图标钮——**后退**（上一句）/ **前进**（已看过的下一句；已在最新进度时直接接着推进下一句，缺内容就现场生成）/ **快进**（连续重放已看过的内容，到最新进度自动停，再点变暂停）。没有可退/可进时对应钮灰掉。
6. **重新生成**：软件标题栏右侧圆形刷新钮（生成中时在转圈指示器左边）。对当前 AI 拍不满意时点它：从剧情树剪掉该拍及其后代（**其它分支留下**），时间线截到该拍之前，立刻重写；若正停在「等待下一段」，则只作废进行中的请求 / 线性预写，再写下一段。预写的静态拍上不显示此钮。
7. **历史与剧情树**：足迹按「句」记在 [`PlayHistory`](../lib/domain/runtime/play_history.dart)；本局 AI 拍与选项边记在 [`BridgeSession`](../lib/domain/runtime/bridge_session.dart)（`generatedBeats` + `branchEdges`），换站不丢。回退改选只改当前足迹，**其它分支内容仍在**，再选时可直接沿已有边进去。回退状态下点屏幕按前进重放，不误触发新生成。
8. **总能继续**：有下一站时用「前往：某站」保底；无下一站时也可「继续 / 告一段落」（看站内选项频率）。出站分叉始终有选项；站内过程拍可以没有选项——点屏幕播完就接下一段。选项最多三个。设置 → AI → **站内选项**（关闭 / 很少 / 有时 / 较多）只影响站内要不要弹选项。
9. **一步多少句**：设置 → AI → **每段最少句数**（默认 **10**，1–10）；写少了自动重试一次。一次生成通常带来多步点屏。
10. **渐进预写**：最新拍无选项时线性预留 2 拍；有选项时一次批写每条可续写选项后的 1 拍（最多 3 路）。标题栏转圈，对白框不写「正在写」。点选不丢其它分支；剧情树进存档；整局重开才清空。

失败与重试：生成失败提示检查文案服务；不要静默吞掉进度。短状态/操作反馈（已复制、连线提示、导入结果等）用顶部居中 [`showAppToast`](../lib/foundation/widgets/app_toast.dart)（不可点，左/右滑可关掉），不用系统 SnackBar。

## 和「会不会太复杂」的对照

| 如果体验是这样 | 复杂度 |
| --- | --- |
| 导入或几句提示词 → 可直接开玩；想控走向再改情节 → 过程 AI 演 | 符合目标，schema 被藏住 |
| 先认识节点、边、节拍，再手写每一句并连线 | 对目标用户过重，不要作为默认 |
| 有情节却玩飞、接不上任何下一站 | 失败；有出边时必须能收敛 |
| 空白故事开玩却只能点「结束」 | 失败；开放区间应能连续生成 |

验收创作入口时检查：**不打开情节图，能不能从导入或空白故事开玩并看到 AI 对白（或中央保底选项）？**  
验收游玩时检查：**点屏能否一句句推进；有分支时选项是否在中央且选完进入定好的下一站；无情节时选完保底/stay 后能否再生成？**

## 主线节点编辑器：交互验收

创作入口仍不从空白画布开始。用户要改走向时，打开的是**同一套节点画布**，底部胶囊可切「卡片」视角。切换只改相机（居中放大当前站），不换另一套 UI；切回画布后自由平移/缩放恢复，图不丢、连线不变。

### A. 节点编辑器（默认，全端一致）

手机、平板、桌面都提供完整节点编辑器，不因「是移动端」换成另一套编辑器。平板按这套验收，不按卡片视角验收。

| # | 验收 |
| --- | --- |
| A1 | 各端都能：平移画布、缩放、选中节点、拖动节点；画布范围随图增长（[`GraphViewport`](../lib/foundation/graph/graph_viewport.dart) 按所有节点的实际边界撑开可平移区域并留一屏余量），站再多也能平移到最后一站并点到它；节点不能拖出画布左上角，其他方向不限；节点色条为站名、内容区左右插头带说明（进入 / 继续·岔路·添加）；右侧出线标题可点开编辑标题与详细说明，并可让 AI 展开；拖插头到另一站左侧连线；连线可点选（高亮线与两端插头）；与「情节走向」标题同行右侧（由右向左）圆形「更多」「重做」「撤销」（与返回同大；不可用时灰掉；桌面 Cmd/Ctrl+Z、Shift+Z / Ctrl+Y）；「更多」打开抽屉可开「显示网格」（LOD 间距，缩放仍疏密舒适）；画布右下角圆形图标钮「整理排版」「加一站」；拖节点整段算一步撤销；整理排版按站关系从左到右分层重排（覆盖当前坐标）；删线在边的编辑浮层里 |
| A2 | 选中节点后，节点上方出现圆形「复制」「编辑」「删除」图标钮（相对节点定位，拖到画布上沿以外仍贴在站顶上方）；编辑打开**按内容收高**的浮层，改站标题、本站目标、种类（开场/过程/转折/结束）与出边列表；复制生成错位的同内容新站（不带连线）；删除先弹出确认（画布按钮与浮层内「删除这一站」相同，仍可用撤销找回）；仅剩一站时不显示删除；本阶段不进完整对白表单（对白归区间 AI） |
| A3 | 手机上的编辑器与桌面是同一套交互（触控代替鼠标），不是功能被砍掉的简化版 |
| A4 | 不依赖悬停才能完成选中、连线、删除 |
| A5 | 画布上看到的块和线 = 故事里的节点和连接；运行时走向与画布一致 |

### B. 卡片视角（底栏切换，默认画布）

编辑器底部有与设置同款的悬浮胶囊导航：**画布** / **卡片**（默认「画布」）。选「卡片」后**仍是同一张画布**：相机把当前选中站缩放到视口中央并适当放大，方便窄屏看清这一站；桌面和平板也能用，行为与手机相同。

```text
画布                             卡片（同一画布）
┌────────────────────┐          ┌────────────────────┐
│  ○──○──○           │   →      │                    │
│     └─○            │          │      ┌──────┐      │
│                    │          │      │ 客栈  │      │
│   [画布] [卡片]    │          │   [画布] [卡片]    │
└────────────────────┘          │      └──────┘      │
                                └────────────────────┘
```

| # | 验收 |
| --- | --- |
| B1 | 选「卡片」后仍渲染完整节点与连线（同一 `GraphViewport`）；当前站居中放大，相机动画到位 |
| B2 | 卡片期间禁用画布平移与双指缩放；点空白不取消选中，避免相机失焦 |
| B3 | 点另一站即选中并相机跟到该站；仍可拖动站、拖插头连线；选中后可用节点上方「复制 / 编辑 / 删除」（与 A2 相同） |
| B4 | 拖完当前站后相机会重新对准该站 |
| B5 | 切回「画布」后恢复自由平移/缩放；节点位置与连接与切换前一致（仅相机复位） |
| B6 | 卡片视角不维护第二份剧情；只是同一张图的聚焦视角 |
| B7 | 底栏主胶囊为「画布」「卡片」；右侧另有独立「全图」胶囊（同款样式、不与两项互斥，打开时高亮）；仅「画布」时可点：在底栏上方停靠半屏走向全览（`AppDockedPanel`，自下快速滑入/滑出、无过弹），再点同一按钮关掉；打开时透明遮罩挡住背后画布点击，点地图外侧只收起全览；节点缩略图地图中央固定与屏幕同比例的半透明方框；在地图上滑动（含上下）平移画布镜头；拖手柄/标题跟手下滑，松手不足回弹、拖够或甩出则收起；切到「卡片」时自动收起；节点图为与画布一致的 PNG，创建/编辑后更新 |
| B8 | 任意窗口宽度都用胶囊底栏（与设置窄屏同款），不改成侧栏 |

增删节点、改连线仍在这张画布上完成；卡片视角的本项验收是「同一画布 + 聚焦相机」。
