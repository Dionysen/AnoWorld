# AnoWorld 用户体验预览

本文描述**用户看见和做什么**，不是实现细节。数据落点对照 [Core.md](./Core.md)、[MainBeat.md](./MainBeat.md)。功能设计变更时同步改本文，避免体验和 schema 各说各话。

界面文案必须面向用户：短、口语、说清能做什么；不出现 Beat、Edge、Transition、schema、token、NativeTavern、LLM、「接入」等内部词或注释口吻。副标题/说明行简明扼要、不说教，末尾不加句号。对用户说：故事、设定、角色、情节、场景、对白、选项。技术设置用通俗标签（服务地址、密钥）。更细约定见 `.cursor/rules/ui-copy.mdc`。

界面文案集中到 [`app_strings_zh.dart`](../lib/app/l10n/app_strings_zh.dart)（契约见 [`app_strings.dart`](../lib/app/l10n/app_strings.dart)），widget 里通过 `context.strings` 读取；加新语言只需再写一个实现并登记。已迁移范围与待迁移清单、为什么不用 ARB，见 [Style.md](./Style.md)「界面文案与多语言」。

## 游玩体验目标（先记住这个）

开玩时二选一（**视觉小说** / **聊天**），进局后不能再改。两种玩法共用设定、角色与（可选）情节素材，但推进方式不同。

- **聊天（对齐酒馆）**：严格「AI 说一段 → 你回一段 → AI 再接着」；底部可点回复选项当作你的发言。情节节点若有，只作提示词里的软约束，不把聊天绑进视觉小说拍子机。
- **视觉小说**：主线站 + 区间 AI；全屏背景、底部对白、点屏推进、选项居中；有出边则收敛，无出边则开放续写（选项里「继续 / 告一段落」）。
- **情节是辅助**：没有脉络也能靠设定与角色开聊或开玩；有脉络时聊天多一层走向提示，VN 多一层站间收敛。

创作入口仍然是「导入 / 贴故事 / 几句提示词」，不是先教用户画节点。对照数据层见 [Core.md](./Core.md)。

## 结论：schema 不该由用户填

一份**能开玩**的故事，系统里至少要有：

| 系统里有什么 | 玩家/作者要不要手填 | 三条路径里谁来补 |
| --- | --- | --- |
| 故事名 | 要，或从导入文件名带出 | 用户确认一下即可 |
| 全局 AI 预设（设置 → 预设） | 可不碰；内置默认即可 | 想换气质或导入酒馆 preset 时去设置 |
| 世界观 / 设定 | 角色卡、小说里通常已有 | 路径 1/2 自动填；路径 3 用一句提示词生成 |
| 角色 | 手建或从卡摘取；可勾一名 **主角** | 同上 |
| 主线概括 + 大情节站 + 分支 | 角色卡里往往没有完整剧情树 | AI 从素材或提示词生成**脉络骨架**；用户可微调站名/走向 |
| 站与站之间的对白过程 | 用户不应手写整本 | **游玩时 AI 实时生成**（可预写开场钩子，非必须） |
| 图片 | 没有也能先玩（占位） | 生图或稍后导入，不挡「开始游玩」 |

所以：**对用户并不复杂——入口是导入或提示词，出口是直接玩；情节图用来事后改大走向，不是第一步。** 用户看到的「能玩」，靠的是「设定/角色可用 + 游玩时 AI 能演下去」；情节骨架是加分项，不是硬门槛。

角色卡通常只有人和设定。导入后即可开玩（开放续写）；若再生成脉络，则多一层分支与收敛。

## 共同壳：三条路之后长一样

无论从哪条路进来，用户落在同一个故事上，之后只有三件事：

1. **玩**：点「开始游玩」先选 **视觉小说** 或 **聊天**（[`showPlayModeSheet`](../lib/play/play_mode_sheet.dart)），选定后整场锁定，并**新建一条存档**（同一故事可有多条）。选 **视觉小说** 后再选 **你扮演谁**（[`showPlayRoleSheet`](../lib/play/play_role_sheet.dart)，列出全部角色，默认主角；只有一名角色时直接用），这个身份存进该存档、本局不能改；玩家开口时自己的角色照常显示立绘。聊天为酒馆式气泡：助手一轮在左、你一轮在右；空输入不发送；点「回复选项」或打字发送都算你的一轮，随后 AI 再生成，回复**边生成边滚字**（SSE 流式，[`TavernChatGenerateAction.streamGenerate`](../lib/domain/chat/tavern_chat_generate_action.dart)），生成中发送钮位置换成停止钮、点了保留已出现的文字；可「换一批」选项。输入栏可换模型（先选模型再选思考程度）、进**聊天设置**（[`ChatSettingsPage`](../lib/play/chat_settings_page.dart)：行距、段间距、气泡圆角、思考过程显隐、角色/我的头像与位置、聊天背景含内置渐变/纯色；只影响聊天页）；顶栏右侧可重新生成上一条助手回复。开玩与每轮进度都会**自动写回**该存档（聊天顶栏只显示故事名，无玩法前缀、无手动保存；视觉小说不画顶栏）。首页**会话**点一条即续玩该槽（不经故事详情，按存档里的扮演角色恢复）；「更多」里仍可打开故事或删这一条。
2. **改**：觉得不对，改设定/角色、改某站目标或分支，或让 AI 重写脉络/重来某一段过程。
3. **补画面**：可先占位；再生图或导入，绑到场景/角色上。

玩和改之间随时切换，不必「写完每一句才允许玩」。

## 首页（底栏：会话 / 故事 / 设置）

首页用 `AppNavShell` 三分区（窄屏悬浮胶囊底栏 / 宽屏左侧栏；断点 **600**，与平台无关——桌面竖屏与手机同一套）：**会话** / **故事** / **设置**。首页**不显示**软件标题栏（`AppPage.showTitle: false`）；桌面仍留空白自定义标题栏（仅背景，可拖动）。**宽窗三个分区统一为 侧栏 | 列表 | 详情 三栏**（宿主 [`AppMasterDetail`](../lib/foundation/widgets/app_master_detail.dart)，几何与拖拽见 [Style.md](Style.md)）：中列是当前分区的列表，右列是**选中项在单栏里点开的那一页**（故事 → 故事详情页、会话 → 该存档的小结、设置 → 玩家身份页或设置分区页），不是另写的摘要卡；未选中时右列保留原宽、居中显示淡色提示（各分区一句：`selectSaveHint` / `selectStoryHint` / `selectMeHint`）。右列自带导航栈（[`AppDetailPane`](../lib/foundation/widgets/app_detail_pane.dart)）：页里再打开的编辑 / 设置页仍 push 在**同一列**，列表列不被盖住，页内返回只退这一列；换选另一个条目时这一列的页面栈清空重来。**一个页面只有一个家**：故事详情页只属于故事分区，所以会话的「打开故事」不在此开页，而是切到故事分区并选中那本（详见下方会话段）。**游玩一律全屏**（视觉小说舞台与聊天都是整窗，覆盖左侧栏）：从会话「继续游玩」或故事页的「开始游玩」进入时推到最外层（`pushAppSlide(fullscreen: true)`），所以会话第三栏放的是这条存档的小结（封面 / 故事名 / 玩法与上次游玩 / 继续游玩·打开故事·删除）。窄窗收回单列，点条目仍走 `pushAppSlide` 进整页；宽窄来回切换时选中项保留。系统返回先退右列栈顶的页，再清右列选中，再退文件夹 / 多选，最后才离开首页。非主页（设置、故事详情等）在窗口/状态 chrome **下方**有软件标题栏（返回 + 标题 + 操作，高度 **44** / `pageTitleBarHeight`）；视觉小说游玩是全屏舞台，没有软件标题栏，返回 / 重新生成 / 设置都在底部控制栏里，舞台背景一直铺到 chrome 后面（桌面标题栏、手机状态栏也看到同一张背景，控件位置不变）。桌面自定义标题栏内不放控件与文字。有搜索的分区：搜索在最上，工具按钮在搜索下一行（正常 `pagePadding`）。全局**设置**就是首页「设置」分区本身：没有单独的设置页、没有齿轮入口，也没有单独设置胶囊；身份行与 通用 / 外观 / 剧情元素 / AI 配置 / 预设 / 生成设置 / 关于 平铺在一起（无分组头、无「添加身份」按钮；各设置行有一行副标题；添加身份在点进身份管理页后操作），点条目进二级页。软键盘对齐 NativeTavern：Android `adjustResize`，[`AppPage`](../lib/foundation/widgets/app_page.dart) 默认随键盘收缩；正文与居中对话框上移避让。悬浮底栏与收起态创作助手按 [`keyboardPinOffset`](../lib/foundation/widgets/app_bottom_nav_icon_capsule.dart) 钉在屏幕物理底边（可被键盘盖住，不跟着对话框弹跳）；展开的创作助手面板仍留在可视区内。抽屉按 `viewInsets` 上移；收起只 [`unfocus`](../lib/foundation/focus/app_keyboard.dart)。

## 路径 1：导入酒馆角色卡

**用户想要的感觉**：选一个卡 → 看软件读懂了什么 → 勾选留下 → 写入故事再改。

**当前实现**：故事页末尾「添加」→「导入角色卡」→ [`CharacterCardImportPage`](../lib/create/character_card_import_page.dart)；支持 `.json`（V2/V3/旧平铺）与带 `chara`/`ccv3` 的 `.png`；读入后**自动去掉网页标记**（正文以 Markdown 存）；可再点「清理格式」；确认后「写入故事」进入故事详情（先看素材，分区编辑直达，不强制立刻开玩 / 生成脉络）。**封面**：PNG 卡直接把卡面图写入故事封面（`assets/cover.png`）；JSON 卡若同目录有同名 `.png`（[`readCardCoverSidecar`](../lib/data/card_import/card_cover_sidecar.dart)）也一并带上；导入页会预览这张封面，没有图则提示可在故事页更换。**卡片信息**：卡上的创作者 / 版本 / 标签 / 创建与修改日期随卡带进故事（存 `ProjectMeta.card`），导入页在封面预览下用小字列出已有项，导入后可在故事详情查看与编辑。macOS 沙盒需 `files.user-selected.read-write`（Debug/Release entitlements）才能读所选卡文件。

### 用户做的事

1. 选择角色卡文件（可多张：第一张作主角与故事名，其余当配角）。
2. 看「读到了这些」：角色、世界书条目；用开关划掉不要的（卡内 system 等不写入故事，提示去设置调全局提示词）。
3. 可选「清理格式」：规则去 HTML，保留 Markdown。
4. 点「写入故事」：生成故事并打开故事详情，继续改设定 / 角色 / 情节。
5. （后续）再生成短脉络骨架并开玩——本阶段不挡写入。

### 软件自动做的事

| 卡里常见内容 | 填到 |
| --- | --- |
| PNG 卡面图（或与 JSON 同名的 PNG） | 故事封面（首张带图的卡；导入页可预览） |
| 创作者（`creator`）/ 版本（`character_version`）/ 标签（`tags`）/ 创建日期（`creation_date` / `create_date`）/ 修改日期（`modification_date`）/ 作者注（`creator_notes`） | 故事卡片信息（`ProjectMeta.card`；故事详情始终列出，空着显示「未填写」，可改） |
| `scenario` | 世界书 · 常驻「情景」 |
| `character_book` 全部条目 | 世界书条目（`constant`→常驻，否则带关键词）；卡里本来就关闭的也列出来，只是导入时默认不勾 |
| `first_mes` | 世界书 · 常驻「开场素材」 |
| `alternate_greetings` | 备选开场（默认不勾选） |
| `name` / `description` / `personality` | 角色 |
| `mes_example` | 角色例句（最多 50 行，避免撑爆上下文） |
| `<BOT>` / `<USER>` / `<CHAR>` / `<GROUP>` 等旧式称呼 | 换成角色 / 玩家 / 同场角色称呼，不丢句子 |
| `system_prompt` / `post_history_instructions` | 不写入故事包；导入后可提示粘贴到设置 → 提示词 |
| 正则、插件 | 不导入 |
| 酒馆 preset 文件 | 设置 → 预设 导入 |

### 体验要点

- 确认页要短：每块一行标题 + 一两行预览，开关决定去留。
- 读卡失败留在本页，不丢已选文件以外的状态；写入失败同样留在确认页。
- 图可以后补；不强制等生图结束。

## 路径 2：导入小说或一段剧情

**用户想要的感觉**：贴上一段故事 → AI 拆成能玩的故事 → 开玩 → 哪段不对改哪段。

### 用户做的事

1. 新建故事，粘贴正文，或导入文本文件。可写一句补充（例如「只做到雨夜投宿为止」「主角是第一人称」）。
2. 等一页结果：设定摘要、登场角色、情节列表（每场一行标题 + 一句发生了什么）。
3. 可删掉某场、改标题，或点「按原文重写这一场」。
4. 点开始游玩。

### 软件自动做的事

从正文抽出并写入：设定、角色、主线概括、**有序大情节站（含一句话目标）与分支**；原文没有分支时，补少量合理岔路并保留「按原文继续」类走向。对白过程留给游玩时 AI（可选预写第一站钩子）。

长文不要一次吞完。体验上先做**用户划定的这一段**（或自动截成「第一章 / 前若干字」并告诉用户范围）。这一段的骨架能玩后，再提供「根据后文续接下一站」。

### 体验要点

- 结果页先给人读「故事被拆成了哪几站」，不要先丢一张节点图。
- 和原文出入大时，用户能对单站重写目标/重滚，而不是整篇推倒。
- 同样允许无图开玩。

## 路径 3：从空白开始，分阶段写提示词

**入口已接通**（路径 2 仍为占位）：故事页「添加」→「分阶段提示词」→ [`StagedCreatePage`](../lib/create/staged_create_page.dart)。需在设置 → AI 配好写故事服务（[`OpenAiChatClient`](../lib/foundation/ai/openai_chat_client.dart) + [`StagedCreateActions`](../lib/domain/ai/staged_create_actions.dart)）。

**目标体验**：每个阶段只写一两句人话；阶段 3 产出的是**脉络骨架**（概括 + 大站 + 分支），开玩后站间由 AI 实时演。

| 阶段 | 用户写什么 | 生成并填入（目标） | 用户此时能做什么 |
| --- | --- | --- | --- |
| 1 世界 | 「雨夜的边城，人们靠传闻活着」 | 设定 | 改设定；还不能完整游玩 |
| 2 人物 | 「少年想离开，客栈老板知道出路」 | 角色 | 改人设；仍建议先有脉络再玩 |
| 3 走向 | 「今晚必须出城，在客栈做一个选择」 | 主线概括 + **大情节站（含目标）+ 分支/结局出口** | **可以开始游玩**（过程戏现场生成） |
| 4 画面（可后做） | 「城门冷色、客栈暖色」或直接生图/导入 | 场景图、立绘 | 再玩时看到图（本阶段尚未做） |

阶段 3 结束就是「能玩」的分界：骨架合法且文案服务可用即可开玩，**不要求**创作时写满对白。

**当前实现**：路径 3「走向」只生成 `summary` + 大站（含 `synopsis`）+ `default`/`branch` 边（`beats` 可空）；故事详情分区可直达设定 / 角色 / 情节 / **画面** 编辑；游玩时空拍进 [`BridgeGenerateAction`](../lib/domain/ai/bridge_generate_action.dart)，失败或未配文案服务时用「前往：{下一站}」保底；样例「雨夜投宿」仍带预写对白作静态对照。路径 1/2 导入未做。

**阶段 4 画面（MVP）**：创作枢纽「画面」一行显示已有 **n 张立绘，n 张场景图**（`avatarAssetId` / `backgroundAssetId` 的条数，都为 0 时写「还没有立绘和场景图」）。进入后首行两个按钮：**一键生成提示词**（文本模型产出统一画风的立绘/场景提示词；画风前缀按 RLI 质量标签模板，笔触由 Comfy 侧所选风格 LoRA 负责；生成完立刻写回故事，落点 `CastMember.visualTags` / `portraitPrompt` / `facing`、`StoryNode.imagePrompt`）与 **一键生成图片**（经 ComfyUI（NoobAI + 设置里选的 LoRA，默认 `RLI(noobai)0.1v`）批量出立绘与每站场景图，步数/分辨率/超分/LoRA 读设置；已有图跳过；出图交给应用级任务 [`VisualImageJobController`](../lib/app/visual_image_job_controller.dart)，离开画面页仍继续画，再进来显示同一条进度（「正在画立绘：某某 · 45%」），画完自动刷新缩略图并提示结果，同一故事同时只跑一个）。下面是「画风 / 角色立绘 / 场景图」三组条目：左边是已生成图片（未生成用占位图；画风前缀与负面提示词用图标），右边是标题 + 两行提示词预览。点条目进全屏抽屉：图片 + 立绘朝向（角色行）+ 提示词编辑，右上角 **保存**；改过没保存就退出会先问「放弃这次修改？」。抽屉里每一行还能单独 **重新生成提示词**（只重写这一条，结果填进输入框，保存后写回）与 **重新生成图片**（先把当前提示词存盘，再按它重画这一张；立绘与场景各有，画风行没有图片）；已有图还可 **删除图片**（确认后删本地文件并清故事引用，画面抽屉、角色编辑、情节站编辑里都有）。点预览放大后看到的是当前文件内容（重画覆盖同一路径也会刷新）。立绘提示强制**完整上半身**（`upper body` + `entire upper body in frame`，头/臂/躯干都要画全）+白底+**较粗黑描边**（`very thick black outline`）+朝向标签，写入与出图前都会剔除 `full body` / `close-up` / `cropped` 等全身或裁切标签，并在立绘负面词里压掉全身与裁切；落盘前做边缘 flood-fill 去背成透明 PNG。场景保持完整环境。情节图底栏「画布 / 卡片」右侧同一组里的 **场景** 钮控制画布下方的场景图面板（默认关；关着时选中站也不显示图片）。打开后选中一站即在画布下方（不盖画布）显示该站场景图，图片按自身比例铺满可用宽度、完整不裁切（高度超出画布余量时等比缩小），下方可「重新画场景」；站编辑抽屉同样可「重新画场景」；角色列表与编辑抽屉显示立绘，可「重新画立绘」（[`VisualImagePipeline.regenerateScene`](../lib/domain/ai/visual/visual_image_pipeline.dart) / `regenerateAvatar`）。所有预览图（编辑抽屉、情节图场景条、角色立绘）点一下即全屏放大：滚轮 / 双指 / 双击缩放并拖动查看，点画面、右上角关闭、返回或 Esc 退出；关闭钮落在标题栏 / 状态栏下方，不与窗口按钮、系统图标重叠（[`showAppImageViewer`](../lib/foundation/widgets/app_image_viewer.dart)）。VN 舞台铺节点背景图，说话人透明立绘按 `Appearance.slot`（或 `facing` 对侧）左右摆，脚底贴在对白框上沿、不再被框挡住；对白框贴近窗口下沿，框下是一排更小的圆钮（返回 / 上一句 / 下一句 / 快进 / 重新生成 / 设置），手机上全面屏手势条自动隐藏、不占空间（见 [Style.md](Style.md)「移动端底部系统条」）；无图仍可玩。

### 创作助手（通用 Agent，已接通）

在故事分区或故事子页点右下角创作助手：面板顶部是「当前故事」（不再有单独的「创作助手」标题），打开故事页时自动切到该故事，也能手动改选；没有编辑范围开关——一次回合全层可读可写，改哪层由模型按你的说法判断。实现见 [`CreateAssistantPanel`](../lib/home/create_assistant_panel.dart) + [`CreateAgentRunner.runTurn`](../lib/domain/ai/create/create_agent_runner.dart) + [`CreateAgentLoop`](../lib/domain/ai/create/create_agent_loop.dart)。

- **先看后改**：系统提示里只放五层的目录（设定/角色标题、站点与出边数、已选剧情元素），模型觉得不够才调工具去读某一条的正文或某个字段；不需要改动时直接回一句话，不弹确认。
- **情节图**：无图或要整图重写 → `main.replace`（至少约 **20** 站、上不封顶，按丰富度加站；分叉目标要拉开；叶可为终局或开放续写）；有图则 `main.patch` 增量改站/边。
- **世界书 / 角色**：`world.patch` / `cast.patch` 提议改条目或角色字段，确认后写回。读可跨层，写也可以在一轮里连写几层，最后合并成一张确认单。
- 确认：半屏抽屉按层分组列出改动，可**单独勾选**要写回的条目，并显示字段级「原 / 改」差异；只写选中项，多层改动一次保存。整图重写占一行，并明说会换掉现有站（有预写对白则一起清掉）。预览与回放见 [`patch_preview.dart`](../lib/domain/main/patch_preview.dart) / [`patch_review_sheet.dart`](../lib/home/patch_review_sheet.dart)。
- **收起不打断**：点面板外或切走分区只会隐藏面板（[`CreateAssistantPanel`](../lib/home/create_assistant_panel.dart) 始终留在树上，隐藏期间 `Offstage` 不绘制也不收点击），正在跑的回合照常继续；写完直接弹确认抽屉，不需要先重新展开助手。
- 刷新：写入后经 [`ProjectChangeNotifier`](../lib/app/project_change_notifier.dart) 通知详情与情节图重读。
- 未选故事、未配写故事服务、模型不支持工具调用、模型输出不可解析时，只回一句可读提示，不改动故事。

每一阶段：输入框 → 生成 → 就地预览可编辑 → 下一步 / 重写。不要在阶段 1 打开情节画布。未配置文案服务时留在当前阶段提示去设置，不丢已写入内容。

### 体验要点

- 提示词旁边给一句例子；预览讲「有哪几站、怎么分支」，不要堆内部字段名。
- 「重写这一阶段」只动这一阶段产物（改人物不默默拆掉已生成的脉络；冲突时标出来让用户决定——待补）。
- 游玩中过程不对：可「重来这一段」或改站目标后再玩；大走向不对：回情节图或重滚阶段 3。

## 故事详情（点进一个故事）

从故事库点一个故事进入 [`ProjectHubPage`](../lib/project/project_hub_page.dart)：上方**封面**为半屏高沉浸英雄区（[`StoryCoverBanner`](../lib/project/story_cover_banner.dart) + [`AppPage.overlayTitle`](../lib/foundation/widgets/app_page.dart)：封面铺到窗顶 / 状态栏后，软件标题透明叠在其上；顶对齐裁切 + 顶/底渐隐；故事名先落在封面底部，上滑后缩小淡出并收到顶栏；有 `assets/cover.*` 时显示真实封面，否则大书本图标占位；换封面与**改故事名**在软件标题右侧）。下方可折叠分区 **世界书**、**角色**、**情节走向**、**剧情元素**、**画面**、**卡片信息**（[`AppDetailSection`](../lib/foundation/widgets/app_detail_section.dart) 标题行即 [`AppListTile`](../lib/foundation/widgets/app_list_tile.dart)，与创作列表同款；默认收起）：点行展开详情，最右**编辑**（`onEdit`）直达对应编辑页（不再经创作中间页）。每区标题下用一行小字给体量与估算 token（世界书「n 条设定，m 条常驻，x token」、角色「n 个角色，x token」、情节走向「n 个节点，x token」、剧情元素「已选 n 项，x token」、画面「n 张立绘，m 张场景图」；空区不显示条数行，展开后见空态说明）。剧情元素区展示本故事已勾选的关键词与描述；空态「还没选剧情元素」。展开后条目以发丝线分隔（标题后紧跟标签 chip，再是正文）；默认每区只先显示前 **8** 条，多出来的用「还有 n 条」；单条正文默认三行预览，右侧**展开**与**复制**。卡片信息展开后始终列出创作者 / 版本 / 标签 / 创建日期 / 修改日期 / 作者注，空着显示「未填写」。故事「更多」里的**查看故事**与**编辑故事**都进同一详情页。右下角 **开始游玩** 用 [`AppCircleButton.fab`](../lib/foundation/widgets/app_circle_button.dart)（先选玩法；视觉小说再选**你扮演谁**，本局锁定）。

## 分区编辑（故事内）

故事详情各区右侧编辑直达对应页；token 由 [`TokenEstimator`](../lib/foundation/text/token_estimator.dart) 估算（非 ASCII 约 1 字 1 token、ASCII 约 4 字 1 token，向上取整），文本取自实际注入内容，汇总在 [`ProjectTokenEstimate`](../lib/domain/project/project_token_estimate.dart)。剧情元素勾选页（[`PlotElementsPickPage`](../lib/create/plot_elements_pick_page.dart)）只从全局库勾选，不改库；可跳转设置里的剧情元素库管理。勾选页标题下有 **全部 / 分类 / 包** 下划线页签（可左右滑切换）：全部直接开关；分类页签列出各分类，点进子页只做勾选；包页签列出元素包，打开开关（或点条目）一次性把包内元素全部勾上，关掉则把包内元素全部取消，副标题显示「已选 m / n 条」。包之间不互斥；与已单独勾过的元素或另一已应用包有重叠时，应用前先弹确认。取消包时别处仍需要的元素不会被取消。选中数量以「已选 n」小字显示在软件标题栏右侧（为 0 时不显示）。设定/角色编辑页、导入角色卡勾选列表同样套用该组合。

## 微调：三条路共用，而且是可选的

开玩之后，用户只会因为「这里不对」进来，而不是为了填满 schema。

| 用户觉得 | 打开的界面 | 背后改的数据 |
| --- | --- | --- |
| 人设/世界观偏了 | 故事详情 → 世界书 / 角色 | WorldBook / Cast |
| 这一站目标不对 / 分支不对 | 故事详情 → 情节走向 | nodes / edges / synopsis |
| 过程戏这段不对 | 游玩中「重来这一段」或创作里预写钩子 | 区间会话 / 可选预写 Beats |
| 想多一个结局或岔路 | 故事详情 → 情节走向 | nodes / edges |
| 输出不对 | 设置 → 预设（提示词分段） | 全局 AiPreset |
| 图不好看 | 图片：再生或换自己的 | 资源槽 |

全端同一套节点编辑器；底栏可切「画布 / 卡片」，见下一节。

## 游玩中：选择、分支与续写

**聊天**：进场 AI 先写开场；你说话或点回复选项后，AI 再写一轮；回合清晰，不替你说话。

**上下文怎么进**：两种玩法同一套规则（[`PlayContextSelector`](../lib/domain/ai/play_context_selector.dart)），不是把整本书塞给模型——

- **必进**：常驻设定（`alwaysOn`）、主角字段、主线概括、当前站目标。
- **命中进**：设定条目按 `keys` 命中近几轮正文才注入（没填 `keys` 的条目按标题匹配），上限 6 条；剧情元素按关键词命中，上限 4 项。
- **不进**：其余条目与未命中的剧情元素留在库里，创作助手仍可点名读取。

扫描范围是最近 6 轮对话或最近 2 拍正文（取末尾约 2000 字）。想让某条设定在相关场景一定出现，给它填关键词即可。

**放不下时先丢旧的**：预算 = 设置里 **上下文** 减去 **单次输出**（[`ContextBudget`](../lib/domain/ai/context_budget.dart)）。聊得久了，最早的几轮对话会先被丢掉，正文里留一句「更早的 n 条对话已省略」；VN 的区间摘要只带最新一截。常驻设定与主角字段不参与丢弃。默认预设的窗口很大，不动 **上下文** 滑块就不会发生裁剪。

**视觉小说**（[`PlaySessionPage`](../lib/play/play_session_page.dart) VN 舞台）：

1. **全屏背景**：背景图铺满整页——桌面窗口标题栏、手机状态栏后面也是同一张舞台图（顶部不另铺实色条），暂时没有图时整面用主题底色留空（不占顶部小卡片）；顶栏控件位置与高度不变。
2. **底部对白**：当前句在屏幕下方、左右底边 `pagePadding`；高度固定为设置里的**行数** × 字号，不随每句长短跳动。面板是半透明磨砂玻璃（`BackdropFilter` 高斯模糊 + `VnUiSettings.opacity` 不透明度，背景色可跟随主题或自选）；角色名在固定高度的首行粗体（默认主题强调色，可被自选文字色覆盖），旁白不显示「旁白」或角色名，正文斜体、颜色可跟随主题或自选。**说话人只认角色**：名字来自 `Cast`；对不上任何角色的名字按旁白显示，绝不把模型写的字符串直接当角色名。**玩家扮演的角色说话时同样上台**：查该角色 `Appearance.spriteAssetId`，没有就用 `avatarAssetId`，与配角一套规则。
3. **点击继续**：没有选项时不出现「继续」等按钮，点屏幕任意处推进。文字**逐字显示**（[`AppTypewriterText`](../lib/foundation/widgets/app_typewriter_text.dart)，速度见游玩设置）：这一句还在写时点一下即补全整句，再点才翻页 / 进入下一句；当前句超过固定行数时先翻到下一页（首行右侧显示「1/2」页码），翻完才进入下一句。流式生成时，已经出现的句子可以正常点屏推进；若玩家已追到最快的那一句、后面还有句子在路上，句尾显示「…」并暂不推进，等新句到达再继续。
4. **中央选项**：有选项、保底「前往：某站」、或本段结束「重新开始」时，选项叠在画面中央（在对白框上方），对齐常见 SLG 做法。
5. **底部控制栏**：对白框下方一排图标钮，居中排布、空间不足自动换行——**返回**（退出本局）/ **后退**（上一句）/ **前进**（已看过的下一句；已在最新进度时直接接着推进下一句，缺内容就现场生成；当前句还有下一页时先翻页）/ **快进**（连续重放已看过的内容，到最新进度自动停，再点变暂停）/ **重新生成** / **游玩设置**。没有可退/可进时对应钮灰掉；生成中「重新生成」位置换成转圈。
6. **重新生成**：底部控制栏的刷新钮。对当前 AI 拍不满意时点它：从剧情树剪掉该拍及其后代（**其它分支留下**），时间线截到该拍之前，立刻重写；若正停在「等待下一段」，则只作废进行中的请求 / 线性预写，再写下一段。预写的静态拍上不显示此钮。
7. **历史与剧情树**：足迹按「句」记在 [`PlayHistory`](../lib/domain/runtime/play_history.dart)；本局 AI 拍与选项边记在 [`BridgeSession`](../lib/domain/runtime/bridge_session.dart)（`generatedBeats` + `branchEdges`），换站不丢。回退改选只改当前足迹，**其它分支内容仍在**，再选时可直接沿已有边进去。回退状态下点屏幕按前进重放，不误触发新生成。
8. **总能继续**：有下一站时用「前往：某站」保底；无下一站时也可「继续 / 告一段落」。出站分叉始终有选项；站内过程拍可以没有选项——点屏幕播完就接下一段。需要分叉时，选项尽量给满设置 → 生成设置 → **站内选项**（**1–4**，默认 **3**；可少不可多）。
9. **一步多少句**：设置 → 生成设置 → **每段最少句数**（默认 **10**，1–10）；写少了自动重试一次。一次生成通常带来多步点屏。
10. **渐进预写 + 流式上屏**：最新拍无选项时线性预留 2 拍；有选项时一次批写每条可续写选项后的 1 拍（路数不超过站内选项上限）。AI 回复按 SSE 流式读入（[`BridgeBeatStreamParser`](../lib/domain/ai/bridge_stream_parser.dart) 边收边解析 `lines` 数组里的每个对白对象），每凑齐一句就交给运行时 [`MainRuntime.appendStreamLine`](../lib/domain/runtime/main_runtime.dart) 直接落在当前拍上，与静态拍一样点屏推进；整批写完后再补选项与场景信息（`updateBeat`）。底部控制栏转圈，对白框不写「正在写」。中途断流时已出现的句子留在屏幕上，并用「继续 / 告一段落」保底，不白屏。点选不丢其它分支；剧情树进存档；整局重开才清空。
11. **续玩提示**：从会话续一局视觉小说时，读回进度的提示只在顶部弹一次 toast「已读取进度」（[`showAppToast`](../lib/foundation/widgets/app_toast.dart)，几秒后自动消失），对白框上方不常驻状态行。
12. **游玩设置**（[`VnSettingsPage`](../lib/play/vn_settings_page.dart)，底部控制栏齿轮进入，只影响视觉小说）：**行数**（默认 **3**）、**字号**（默认 **14**）、**文字边距**默认 **85% 字号**、**对话框边距**默认 **50% 字号**（只管左右）、**控制按钮**默认 **200% 字号**、**按钮上/下间距**默认各 **20% 字号**、**文字速度**默认 **28** 字/秒、**不透明度**默认 **40%**，以及「颜色」分区的**背景颜色**与**文字颜色**（各自可自选，也可用「跟随主题」开关回到主题色；文字色同时作用于角色名与正文）。设置存进 [`VnUiSettings`](../lib/domain/settings/vn_ui_settings.dart)，开下一局仍生效。

失败与重试：生成失败提示检查文案服务；不要静默吞掉进度。短状态/操作反馈（已复制、连线提示、导入结果等）用顶部居中 [`showAppToast`](../lib/foundation/widgets/app_toast.dart)（不可点，左/右滑可关掉），不用系统 SnackBar。

## 和「会不会太复杂」的对照

| 如果体验是这样 | 复杂度 |
| --- | --- |
| 导入或几句提示词 → 可直接开玩；想控走向再改情节 → 过程 AI 演 | 符合目标，schema 被藏住 |
| 先认识节点、边、节拍，再手写每一句并连线 | 对目标用户过重，不要作为默认 |
| 有情节却玩飞、接不上任何下一站 | 失败；有出边时必须能收敛 |
| 空白故事开玩却只能点「结束」 | 失败；开放区间应能连续生成 |

验收创作入口时检查：**不打开情节图，能不能从导入或空白故事开玩并看到 AI 对白（或中央保底选项）？**  
验收游玩时检查：**点屏能否一句句推进（长句先翻页、对白框高度不变）；有分支时选项是否在中央且选完进入定好的下一站；无情节时选完保底/stay 后能否再生成？**

## 主线节点编辑器：交互验收

创作入口仍不从空白画布开始。用户要改走向时，打开的是**同一套节点画布**，底部胶囊可切「卡片」视角。切换只改相机（居中放大当前站），不换另一套 UI；切回画布后自由平移/缩放恢复，图不丢、连线不变。

### A. 节点编辑器（默认，全端一致）

手机、平板、桌面都提供完整节点编辑器，不因「是移动端」换成另一套编辑器。平板按这套验收，不按卡片视角验收。

| # | 验收 |
| --- | --- |
| A1 | 各端都能：平移画布、缩放、选中节点、拖动节点；画布范围随图增长（[`GraphViewport`](../lib/foundation/graph/graph_viewport.dart) 按所有节点的实际边界撑开可平移区域并留一屏余量），站再多也能平移到最后一站并点到它；节点不能拖出画布左上角，其他方向不限；节点色条为站名、内容区左右插头带说明（进入 / 继续·岔路·添加）；右侧出线标题可点开编辑标题与详细说明，并可让 AI 展开；拖插头到另一站左侧连线；连线可点选（高亮线与两端插头）；与「情节走向」标题同行右侧（由右向左）圆形「更多」「重做」「撤销」「一键生成情节」（与返回同大；不可用时灰掉；桌面 Cmd/Ctrl+Z、Shift+Z / Ctrl+Y）；「一键生成情节」按当前世界书、角色、已选剧情元素与设置里的写故事偏好（服务 / 预设 / 最少站数）生成整图，内部固定提示词、不经创作助手对话；生成后走与创作助手相同的半屏确认抽屉（`showPatchReviewSheet` / [`WholeGraphReview`](../lib/home/whole_graph_review.dart)），确认后才写入；「更多」打开抽屉可开「显示网格」（LOD 间距，缩放仍疏密舒适）；画布右下角圆形图标钮「整理排版」「加一站」（底栏「场景」钮打开后，选中站时的场景图面板排在这排钮下方的画布外，按原图比例铺满宽度、不与钮重叠；关闭时不显示图片）；拖节点整段算一步撤销；整理排版按站关系从左到右分层重排（覆盖当前坐标）；删线在边的编辑浮层里 |
| A2 | 选中节点后，节点上方出现圆形「复制」「编辑」「删除」图标钮（相对节点定位，拖到画布上沿以外仍贴在站顶上方）；编辑打开**按内容收高**的浮层，改站标题、本站目标、种类（开场/过程/转折/结束）与出边列表；复制生成错位的同内容新站（不带连线）；删除先弹出确认（画布按钮与浮层内「删除这一站」相同，仍可用撤销找回）；仅剩一站时不显示删除；本阶段不进完整对白表单（对白归区间 AI） |
| A3 | 手机上的编辑器与桌面是同一套交互（触控代替鼠标），不是功能被砍掉的简化版 |
| A4 | 不依赖悬停才能完成选中、连线、删除 |
| A5 | 画布上看到的块和线 = 故事里的节点和连接；运行时走向与画布一致 |

### B. 卡片视角（底栏切换，默认画布）

编辑器底部有与设置同款的悬浮胶囊导航：**画布** / **卡片**（默认「画布」）。选「卡片」后**仍是同一张画布**：相机把当前选中站缩放到视口中央并适当放大，方便窄屏看清这一站；桌面和平板也能用，行为与手机相同。

```text
画布                             卡片（同一画布）
┌────────────────────┐          ┌────────────────────┐
│  ○──○──○           │   →      │                    │
│     └─○            │          │      ┌──────┐      │
│                    │          │      │ 客栈  │      │
│   [画布] [卡片]    │          │   [画布] [卡片]    │
└────────────────────┘          │      └──────┘      │
                                └────────────────────┘
```

| # | 验收 |
| --- | --- |
| B1 | 选「卡片」后仍渲染完整节点与连线（同一 `GraphViewport`）；当前站居中放大，相机动画到位 |
| B2 | 卡片期间禁用画布平移与双指缩放；点空白不取消选中，避免相机失焦 |
| B3 | 点另一站即选中并相机跟到该站；仍可拖动站、拖插头连线；选中后可用节点上方「复制 / 编辑 / 删除」（与 A2 相同） |
| B4 | 拖完当前站后相机会重新对准该站 |
| B5 | 切回「画布」后恢复自由平移/缩放；节点位置与连接与切换前一致（仅相机复位） |
| B6 | 卡片视角不维护第二份剧情；只是同一张图的聚焦视角 |
| B7 | 底栏主胶囊为「画布」「卡片」；右侧另有独立「全图」胶囊（同款样式、不与两项互斥，打开时高亮）；仅「画布」时可点：在底栏上方停靠半屏走向全览（`AppDockedPanel`，自下快速滑入/滑出、无过弹），再点同一按钮关掉；打开时透明遮罩挡住背后画布点击，点地图外侧只收起全览；节点缩略图地图中央固定与屏幕同比例的半透明方框；在地图上滑动（含上下）平移画布镜头；拖手柄/标题跟手下滑，松手不足回弹、拖够或甩出则收起；切到「卡片」时自动收起；节点图为与画布一致的 PNG，创建/编辑后更新 |
| B8 | 任意窗口宽度都用胶囊底栏（与设置窄屏同款），不改成侧栏 |

增删节点、改连线仍在这张画布上完成；卡片视角的本项验收是「同一画布 + 聚焦相机」。
