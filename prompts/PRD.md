# AnoWorld PRD（MVP）

## 一句话

AnoWorld 是用 Flutter 做的**视觉小说创作器 + 运行时**：本地配置 AI API，结构化创作剧本，用聊天式 / 视觉小说式双模式验本与游玩。SillyTavern 角色卡仅作素材入口，不是兼容目标。

## 目标与非目标

### 目标

- 快速从设定落到可玩的一小段故事（创作 → 双模式播放 → 存读档）。
- 创作器与运行时职责分离；同一套内容模型驱动两种播放 UI。
- 跨平台（Windows / macOS / Linux / Android / iOS）一套代码，UI 视觉与交互一致。
- 可配置 AI API，按固定创作动作辅助生成与润色。
- 可选择性摘取 ST 角色卡字段，转为 AnoWorld 素材后二次创作；也可纯手建。

### 非目标（明确不做）

- 不做 SillyTavern 替代品或行为兼容层。
- 不做正则、插件、ST 扩展脚本、完整世界书优先级引擎（世界书是否借鉴见 Core，MVP 待定）。
- 不做云同步、在线分享、Live2D 等重资源管线（后续再议）。
- 不做「一个万能 AI 聊天框写完全稿」；AI 以结构化动作为主。

## 产品形态

| 层 | 职责 |
| --- | --- |
| **创作器** | 项目管理、预设、设定与角色、主线/支线骨架、Beat 编辑、ST 素材摘取、AI 辅助动作 |
| **运行时** | 聊天式播放、VN 式播放、存档/读档；只消费可运行内容，并受当前预设约束 |

两者可同 App 内切换入口，但数据流与界面职责分开：创作改内容，运行只读内容 + 写进度。

## 技术约束

- 语言 / 框架：Dart + Flutter。
- UI：各平台一致；业务页只用基础设施封装组件；样式来自主题。
- 分层：`presentation → domain → data`；可移植能力放基础设施目录，无业务命名渗入。
- 存储：MVP 本地优先（项目文件 / 本地库）；API Key 等敏感配置本地安全存放。
- 网络：仅用于用户配置的 AI API（及日后可选的出图等）；核心游玩不依赖自建后端。

## 内容与播放（摘要）

详见 [docs/Core.md](../docs/Core.md)。

- 内容分层：Preset → Background → Cast → Main → Side（定式）→ Beat/Scene。
- Preset 管文风 / 输出禁用 / 输出偏好（借鉴酒馆预设思路，不做 ST 预设兼容）。
- 聊天式与 VN 式**共用 Beat/Scene 状态**，只换呈现。
- MVP 播放挂在章节/场景上下文下，避免与主线完全脱节的双内容体系。

## 素材：SillyTavern 角色卡

- 支持常见角色卡 JSON（如 V2/V3）解析。
- 用户**勾选字段**导入（描述、性格、首条消息、示例对话等），映射到 Background / Cast。
- 导入后按 AnoWorld 模型编辑；不保证与 ST 原卡行为一致。

## AI 辅助（按动作，非闲聊）

MVP 优先固定动作（输入输出可进编辑器、可撤销、可再生成），例如：

- 从一句话生成 Background 大纲
- 从主线概括拆章节 / Beats
- 按支线定式生成一集支线
- 为某 Beat 生成选项与后果摘要
- 润色对白 / 统一文风

设置项：API Base URL、Key、Model 等，可移植、可更换。生成与续写时注入项目当前 **Preset**（文风、禁用、偏好），与 Background 分离。

## 游玩模式

1. **聊天式**：气泡流、续写、可选回复；交互参考 ST 观感，状态仍来自当前场景 + 历史 + 设定检索范围。
2. **视觉小说式**：场景图、角色图、对白、回复选项；同一状态的舞台化呈现。

资源：MVP 以用户自备图片为主；AI 出图接口不做 MVP 必选项。

## MVP 成功标准（闭环）

1. 新建项目 → 填写 Background + 主线概括  
2. 手建或从 ST 卡摘取 1–2 个角色  
3. 手动或 AI 得到一小段可连的 Beats（约数个～十来个节点即可）  
4. VN 模式完整可玩；聊天模式可在同一段上下文中续写/选项推进  
5. 存档 / 读档可用  

刻意延后：复杂世界书权重、多线并行编辑器、完整 ST 对等、云与分享、重型演出资源。

## 编辑器默认取向（MVP）

- 以**章节列表 + 章内 Beat 列表/详情**为主，不做完整节点图画布（降低第一版复杂度）。
- 产品偏**作者工具**：创作器能力完整优先；运行时足够验本与游玩即可。

## 待决（不阻塞 MVP 开工）

- 世界书：仅 Background 文本块，或最小「可检索条目」——见 Core，标记待定。
- 聊天是否允许「章节内有限自由聊」的幅度（默认：挂在当前章节/场景下续写）。
